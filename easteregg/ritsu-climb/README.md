# 리츠 생일 오르기 게임 — 움직임 시제품

명세 = devpapers `ref/ritsu-climb/MVP_SPEC.md` (구현 결과 §12). **main 병합 · 배포 대상 아님.**
도형(원 · 선)만으로 만든 움직임 시험판이다. 그림 · 보상 · 사이트 이식은 아직 없다.

## 파일

| 파일 | 내용 |
|---|---|
| `proto.html` | 시제품 한 파일(외부 요청 0). `<script id="climb-logic">` = DOM 없는 물리 계산, 그 아래 = 입력 · 그리기 |
| `sim.cjs` | Node 검증 — `node sim.cjs` 로 합격 기준 1~7 검사(검증 봇 완주 포함), `node sim.cjs route route.json` 으로 봇 조작 기록 |
| `route.json` | 검증 봇의 완주 조작(물리 단계마다 목표 하나). `?replay=1` 이 재생한다. 코스 · 물리를 바꾸면 위 명령으로 다시 만든다 |

## 여는 법

```bash
cd easteregg/ritsu-climb
python -m http.server 8110 --bind 0.0.0.0
# PC   http://localhost:8110/proto.html
# 폰   http://<PC 의 Tailscale 주소>:8110/proto.html   (이 PC 방화벽은 8081~8112 만 열려 있다)
```

주소 뒤에 붙이는 것:

| 붙임 | 효과 |
|---|---|
| `?debug=1` | 조정값 슬라이더 · 팔 길이 원 · 목표점 · 접촉 방향 표시, 물리 계산 시간. 폰에서는 「조정」 버튼으로 연다. 「값 복사」 = 현재 조정값 JSON |
| `?input=rel` | 이동량 방식 — 포인터를 움직인 양만큼 도구가 움직인다(PC 는 화면을 한 번 눌러 커서 잠금, Esc 로 풀기) |
| `?replay=1` | 검증 봇의 완주를 재생해 보여 준다(약 48초) |

## 조작

- PC: 마우스를 움직이면 도구 끝이 커서 쪽으로 간다(누를 필요 없음).
- 폰: 화면을 누른 채 움직이면 도구 끝이 손가락 쪽으로 간다. 손을 떼도 그 자리를 유지한다.
- 요령: 끝을 땅에 **눌러 짚어야** 붙는다(살짝 대기만 하면 미끄러진다). 짚은 채 포인터를 반대로 당기면 몸이 끌려간다. 빠르게 휘두르면 튕겨 오른다.
