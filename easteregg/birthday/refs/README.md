# 참고 이미지 (이 폴더에는 이미지를 올리지 않았다)

제3자(공식 · 스토어 · 소셜)의 화면을 캡처한 것이라 공개 저장소에 올리지 않았다. 필요하면 아래 검색어로 구글 이미지에서 다시 모은다(운영자 PC 의 원본은 임시 폴더라 사라졌을 수 있다).

| 용도 | 구글 이미지 검색어 | 찾아야 할 것 |
|---|---|---|
| 5명 동물 캐릭터 | `yumemita animal` | 「yumemita animals completed version」(파랑 곰 · 분홍 토끼 · 노란 여우 · 보라 강아지 · 분홍 동물 한 줄 도열), TikTok 루프 GIF(분홍 · 노랑 · 보라), 「Making of MV Illustrations & LINE Stickers」(밤 공원에 6마리), LINE 스티커(노란 여우 · 분홍 토끼 · 파란 곰), Reddit 「What animal is Yuno supposed to be?」(유노 클로즈업) |
| 마루군 | `뮤타입 마루군` | 부시로드 크리에이티브 한국공식 「뱅드림 유메미타 미야코의 마루군 인형」(분홍 푸들형 인형), 같은 결과의 2D 일러스트(별 장식 · 혀 내민 윙크) |
| 신라면 봉지 | `신라면 봉지 누끼` | 정면 봉지 이미지(붉은 바탕 · 검정 붓글씨 辛 · 금빛 한자 무늬 · 검정 하단 띠 · 면 그릇) |
