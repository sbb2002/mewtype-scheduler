# 생일 배경화면 명세 (v0.2, 2026-10-30)

상태: v0.1 을 Claude 가 쓰고, Codex(codex-cli 0.166.0, `codex exec -s read-only`)가 검토했다. 아래 「5. 협의 결과」가 반영분이다. 아티팩트 시제품은 Claude 가 만들고, 사이트 이식 · 성능 · 접근성 통합은 Codex 가 맡는 분담을 Codex 가 제안했고 Claude 가 수용했다.

## 1. 목적
멤버 생일 당일(KST 00:00~24:00) 사이트 배경을 그 멤버의 전용 장면으로 바꾼다. 캐릭터가 움직이고, 원근감 있는 바닥과 깊이 있는 레이어로 입체감을 준다.

## 2. 공통 규칙
- 렌더링: SVG 레이어(원경 · 바닥 · 중경 · 캐릭터 · 전경) + 캔버스 폭죽. WebGL 은 쓰지 않는다(1차). 입체감 = 소실점 원근 바닥(가로선은 수평선 근처에서 촘촘하고 가늘고, 보는 사람 쪽으로 올수록 간격이 벌어지고 굵어짐) + 포인터 패럴랙스(레이어별 깊이 계수).
- 캐릭터 = 멤버마다 독립 함수. 공식 도안 이미지를 받으면 해당 함수만 교체한다.
- 모션 줄이기: 모든 애니메이션 · 바닥 이동 · 폭죽 정지, 정지 장면만 표시.
- 성능: 탭이 숨겨지면 루프 정지, 폭죽은 3초 안에 종료, 입자 수 상한 150.
- 접근성: 배경은 `aria-hidden`, 글자는 장식(생일 문구)뿐이며 본문 위에 올리지 않는다.
- 상표: 신라면은 상표와 포장 도안을 쓰지 않는다. 붉은 컵라면 봉지 + 「辛」 한 글자로 표현한다.

## 4. 확인 필요
- 공식 도안(5명)은 아직 받지 못했다. 현재 캐릭터는 설명을 바탕으로 그린 임시 도안이다. 특히 **마루군** 의 실제 생김새는 확인되지 않아 둥근 강아지로 가정했다.
- 3D: 1차는 의사 3D(원근 + 패럴랙스). 진짜 3D(Three.js, glTF)는 2차 후보.
- 사이트 이식 시 `bgdeco.js` 와의 관계(생일에만 대체 vs 위에 덮기), 모바일 성능, 밝은 테마에서의 가독성은 이식 단계에서 정한다.
- 공식 도안을 SVG 로 따서 싣는 것의 저작권 판단은 운영자 결정.

## 5. 협의 결과 (Codex 검토 반영)
수용:
- 원근 표현 정정: v0.1 의 「소실점으로 다가오며 굵어짐」은 표현이 거꾸로였다. 위 2번 항목으로 고쳤다.
- 성능 예산은 입자 수만이 아니다: 캔버스 DPR 상한(2), 모바일은 효과 축소, SVG 블러 · 발광 면적 제한, 반복 도형 사전 렌더링.
- 숨김 탭: JS 루프와 CSS 애니메이션 모두 정지. 복귀 시 밀린 폭죽이 몰리지 않게 시간차를 버린다.
- 접근성: `aria-hidden` 만으로 부족. 「배경 끄기」 스위치, 지속 모션 일시정지, 번쩍임 제한(초당 3회 이하), 밝은 테마 대비, `pointer-events: none` 을 명시.
- 입체감 보강(WebGL 없이): 모든 레이어가 같은 수평선 · 소실점 · 광원 방향을 쓴다. 캐릭터 발밑 접촉 그림자, 부유물 그림자(높을수록 퍼지고 옅음), 전경 가림, 원경 저대비, 마법진은 바닥 평면에 투영해 평면 안에서 회전. 패럴랙스는 작게, 터치에서도 기본 구도가 성립.
- 빠진 항목 추가(이식 단계): KST 생일 데이터, 열린 탭의 자정 전환, 날짜 강제 미리보기(`?bday=`), 로딩 실패 시 대체 화면, `bgdeco.js` 와의 중복 실행 · 정리 규칙.
- 도안 교체 인터페이스: 함수 하나가 아니라 기준점(발 위치) · 크기 · 관절 이름 · 그림자 접점을 약속한다.
- 검증 순서: 유노(원근 · 이퀄라이저)로 구조를 먼저 확인, 미야코(3캐릭터 · 마법진)로 복잡도를 확인한 뒤 나머지.

보류 · 이견 없음:
- Three.js 는 이번 범위에서 쓰지 않는다. 카메라 회전이나 입체 모델이 핵심일 때 재검토(Codex 와 Claude 일치).
- 가장 어려운 장면 = 미야코(비례 · 가림 · 접지 + 마루군 도안 불명), 다음 = 노노카 기타 스트럼.

분담:
- 시제품(아티팩트): Claude. 이식 · 성능 · 접근성 통합: Codex 검토 또는 구현. Codex 는 「어느 쪽이 더 예쁘게 만든다는 근거는 없다」고 답했다.
