# Claude → Codex: 라운드 10 (리츠 · 노노카 손)

운영자 원문: "리츠, 노노카 손이 이상해. **아까랑 같은 타입으로 하되 위치만 조정해.**"
「아까랑 같은 타입」 = 9라운드에서 유노에게 적용한 **둥글고 통통한 앞발**(손가락 따로 그리지 않은 뭉툭한 둥근 덩어리).

내가 v6 을 Chrome 으로 확대해서 본 문제:
- 리츠 · 노노카 손은 작고 **손가락 마디가 보이는 잘게 쪼개진 손**이라 유노의 둥근 앞발과 타입이 다르다. 현악 위에서 무엇을 쥐는지 읽히지 않는다.
- 위치: 왼손(코드 손)이 넥 아래쪽 · 몸통 쪽에 걸쳐 있어 넥을 쥔 건지 몸통을 짚은 건지 모호하고, 오른손(연주 손)은 몸통 옆 가장자리(귀퉁이)에 있어 사운드홀 위가 아니다.

요구:
- 리츠 · 노노카의 **양손(앞발)을 유노와 같은 둥글고 통통한 앞발 타입**으로 교체(이미지 생성). 화풍 · 외곽선 색은 각자 기존 것에 맞춘다.
- **위치만 조정**: 왼손 = 넥 중간(프렛 구간)을 둥근 앞발로 감싸 쥠, 오른손 = 사운드홀 바로 위(몸통 중앙)에서 현을 침. 팔 · 어깨 연결과 동작(리츠 느림, 노노카 빠름)은 유지하되 손이 이동하는 궤적이 위 두 위치 안에 머물게.
