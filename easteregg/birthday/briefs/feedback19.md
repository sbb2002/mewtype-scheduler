# Claude → Codex: 라운드 19 (이퀄라이저 — 실제 스펙트럼 애널라이저 패턴)

운영자 원문: "마음에 들어. **뒤의 이퀄라이저의 비트는 좋아.** 그런데 **좌우 좌우로만 움직여서** 느낌이 안 살아. **실제 이퀄라이저의 패턴으로 해.**"
v15 를 바탕으로 한다. **박(킥 1·3 / 스네어 2·4) 타이밍과 유노와의 동기는 그대로 유지**하고, 막대들의 **움직이는 모양**만 실제 오디오 스펙트럼 애널라이저처럼 바꾼다.

## 현재 문제
막대 높이가 좌측 ↔ 우측으로 번갈아 몰렸다 풀리는 단순 대칭/파동 패턴이라 「좌우 좌우」로만 보인다. 실제 이퀄라이저는 그렇지 않다.

## 요구 (네가 실제 스펙트럼 애널라이저/레벨미터 동작을 아는 대로 설계해라 — 설계를 `design_notes.md` 19라운드에 먼저 적어라)
- **주파수 대역별 개별 동작**: 막대마다 대역(저음 → 고음)이 정해져 있고 각자 **독립적으로** 오르내린다. 저음 대역은 킥에 크게 쿵 튀고 천천히 떨어지며(느린 release), 중음은 보컬/스네어에 맞춰 중간 속도, 고음은 하이햇처럼 작고 빠르게 지글거린다(빠른 attack/release, 잔떨림).
- **어택은 빠르고 릴리즈는 느리게**(비대칭 엔벨로프): 치솟는 건 거의 즉시, 내려오는 건 중력처럼 부드럽게. 막대마다 release 속도가 조금씩 다르다.
- **피크 홀드 캡**: 각 막대 위에 얇은 캡(최고점 표시)이 잠깐 머물렀다가 천천히 떨어진다.
- **스펙트럼 기울기(pink-noise tilt)**: 평균 높이가 저음 → 고음으로 갈수록 자연스럽게 낮아지는 형태(왼쪽이 크고 오른쪽이 작은 것이 평균이되, 매 순간 모양은 계속 바뀜). 인접 막대끼리는 서로 영향을 주는 부드러운 언덕(스무딩)이 생기되 완전히 매끈하지는 않게 약간 울퉁불퉁.
- **좌우 번갈아 규칙 제거**: 좌/우 반쪽을 대칭 · 교대로 구동하지 마라. 필요하면 화면 좌우 양쪽 막대 그룹은 **같은 스펙트럼의 서로 다른 샘플**(약간 다른 위상/랜덤 시드)로 구동해 거울처럼 똑같이 움직이지 않게 한다.
- **박 연동 유지**: 킥 순간(1·3박)에 저음 막대 군이 일제히 큰 피크, 스네어/백비트(2·4박)에 중고음 군이 피크 — v15 의 박 정렬(유노 액센트와 30ms 이내)을 깨뜨리지 말 것. 그 사이 구간은 결정론적이되 반복이 눈에 띄지 않는 의사난수(시드 고정, 8~16마디 주기)로 변화를 준다.
- 번쩍임 금지(밝기 점멸 만들지 말 것 — 높이만 변함) · 정지/모션 줄이기 · 화면 이탈 금지 유지. 막대 개수/색/위치는 기존 유지(필요하면 개수만 약간 조정 가능). 유노 · 다른 캐릭터 그대로.
- 결과 = `birthday_bg_v16.html`(`assets5/build_v16.py`, v15 이하 보존).
- 검증: Chrome 으로 유노 장면의 이퀄라이저 영역을 한 마디 동안 10~12 시점 확대 캡처(`qa/shots19/`)해 직접 보고, 「좌우 교대로 읽히지 않는가 · 저/중/고음 움직임이 구분되는가 · 피크 캡이 보이는가」 평가. 박 정렬(고개 · 페이더 · 저음 피크)은 v15 와 같은 방식으로 숫자 재측정해 오차를 보고. 아쉬운 점 솔직히.
