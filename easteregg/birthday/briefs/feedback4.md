# Claude → Codex: 라운드 4 (운영자 피드백)

운영자 원문 요지: 「아까보다 더 좋아졌다. 그런데 **투박한 느낌**이다. **제시한 이미지와 완전 똑같이** 그려라. **동글동글한 느낌이 포인트**다.」

## 내 진단 (왜 투박한가)
v2 3라운드의 윤곽은 `L` 직선 꼭짓점이 많은 **다각형**이다(몸통 `M-34 -73Q-44 -39 …L…`, 귀 · 털 삐죽, 재킷 `L` 자락 등). 참고 이미지(`refs3/`, `refs/`)의 캐릭터는 **윤곽 전부가 둥근 곡선**이다.
- 머리: 거의 완전한 둥근 타원(가로가 살짝 넓음). 머리 높이가 전체의 **55~65%**.
- 몸: 머리 아래 달린 **작고 통통한 달걀형**. 어깨 · 허리 각이 없다.
- 팔다리: 짧고 **둥근 소시지/타원**. 손가락 표현 없음.
- 귀: 곰 · 토끼 · 여우 모두 **끝이 둥글거나** 부드럽게 휜 형태(여우도 뾰족하되 모서리가 둥글다).
- 눈: 점이 아니라 **큼직한 둥근 타원 + 흰 하이라이트 2개**(유노 클로즈업 참고), 또는 웃는 **^ ^ 호선**. 반쯤 감긴 졸린 눈 금지.
- 입: 아주 작은 「ω」 또는 「w」 모양, 코는 작은 점/역삼각.
- 볼: 분홍 큰 타원. 외곽선은 **가늘고 균일한 한 가지 굵기**, 색은 면보다 약간 진한 같은 계열(검정 아님).
- 털 표현(삐죽 윤곽)은 최소화. 미야코의 푸석한 털도 **둥근 덩어리 가장자리를 살짝 물결**치게 하는 정도.

## 작업 방식 (중요)
1. **캐릭터 시트를 먼저 만들어라**: `character_sheet.html` — 5명(+오리 · 마루군)을 크게(각 400px 이상) 나란히 그려 놓고 **참고 이미지를 실제로 옆에 띄워서**(Chrome으로 `refs3/*.png` 를 열어) 눈으로 비교하며 고쳐라. 최소 3번 「비교 → 차이 목록 → 수정」을 반복해라. 이 과정과 마지막 남은 차이를 `design_notes.md` 에 적어라.
2. **경로 규칙**: 윤곽은 원/타원(`ellipse`, `circle`)과 **부드러운 베지어(`C`/`Q`/`S`/`T`)**만 사용. 윤곽선에 직선 `L` 꼭짓점을 쓰지 마라(소품 — 건반, 기타 목, 데크 — 은 예외). 모서리처럼 보이는 곳도 `stroke-linejoin="round"` + 곡선으로.
3. 시트에서 합격하면 그 도안을 `birthday_bg_v2.html` 의 `fox / ferret / bear / maltese / rabbit / duck / maru` 로 옮겨라. 배경 · 신라면 봉지 · 움직임 구조(눈 깜빡임, 귀 까딱, 숨쉬기, 기타 스트럼)는 유지.
4. 비례가 바뀌므로 각 장면에서 캐릭터 발 위치 · 그림자 · 소품(마이크, 기타, 건반, 헤드셋, DJ 데크) 위치가 어긋나지 않게 다시 맞춰라.

## 캐릭터별로 특히 확인할 것 (참고 이미지에서 직접 확인)
- 아라레: 둥근 얼굴 + 크고 끝이 둥근 삼각 귀 + 볼 털 뭉치(물결 선 2~3개) + 크림색 꼬리 끝. LINE 스티커의 표정(^ ^ 웃는 눈 또는 큰 눈)을 따라라.
- 유노: **얼굴이 둥글고 납작**한 분홍 동물, 머리 한쪽이 **붉은 분홍**으로 갈린 무늬(앞머리 같은 곡선 경계), 작고 둥근 귀, 큰 눈에 하이라이트, 헤드셋 + 입가 마이크. 몸은 점퍼를 입은 짧은 달걀형.
- 리츠: 둥근 하늘색 곰, 둥근 귀, 둥근 주둥이 부분(밝은 색 타원), 큰 둥근 눈. 기타.
- 미야코: 보라색 푸석푸석한 강아지 — 그러나 **실루엣은 둥글게**(머리 + 처진 둥근 귀), 눈은 작고 처졌어도 둥근 느낌, 건반을 든 짧은 팔. 탁한 회보라 대신 **채도 있는 보라**.
- 노노카: 분홍 토끼, 긴 귀(끝이 둥근 긴 타원), 둥근 얼굴, 기타.
