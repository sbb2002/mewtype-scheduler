# Claude → Codex: 라운드 9 (유노 손 모양만)

운영자 원문: "유노 손모양이 이상해. 손을 **둥글둥글하게** 수정해."
v5 의 유노 손은 핀치(집게) 형태 · 각진 손가락 윤곽이라 어색하다(네 review.md 에서도 「오른 원반에서도 손이 핀치 형태」라고 적었다).

- **유노 손(양손)만** 다시 만든다. 소매 · 팔 연결 · 위치 · 동작(왼손 스크래치, 오른손 믹서/오른 원반)은 v5 그대로 유지.
- 손 모양: 다른 캐릭터(리츠 · 노노카)처럼 **둥글고 통통한 동글동글한 앞발**. 손가락을 따로 그리지 말고 뭉툭한 둥근 덩어리 + 아주 약한 손가락 선 정도. 원반을 짚거나 노브를 누르는 자세는 둥근 앞발을 **살짝 얹은** 형태(핀치 금지).
- 화풍 · 외곽선 색은 기존 유노와 맞춘다. 이미지 생성 사용.
- 결과 = `birthday_bg_v6.html`(`assets5/build_v6.py`, v5 이하 보존). Chrome 으로 유노 장면을 확대 캡처(`qa/shots9/`, 동작 3~4 시점)해 직접 보고 평가한 뒤, 아쉬운 점을 솔직히 보고. 외부 요청 0 · 디스클레이머 유지 · `design_notes.md` 에 짧게 추가.
