# Claude → Codex: 라운드 13 (미야코 왼쪽 오리 → 청둥오리 도트)

운영자 원문: "미야코의 좌측에 있는 오리는 그냥 오리가 아니라 **청둥오리**야. 이 도트 이미지를 써." 첨부 `refs7/mallard_ref.png`(운영자가 직접 받은 청둥오리 도트 아이콘, 초록 머리 · 흰 목 줄무늬 · 갈색 가슴 · 회색 몸 · 갈색 등 · 검은 꼬리 · 노란 부리, 왼쪽을 봄).

- 장면의 `duck` 을 이 도트 청둥오리로 **교체**한다. 운영자는 이 도트 이미지를 **쓰라고** 했으므로 도트 스프라이트 자체를 사용한다(`image-rendering: pixelated` 로 정수배 확대, 흐려지지 않게). 주변의 둥근 셀 화풍과 이질감이 크면 어떻게 처리할지(예: 연한 외곽선 · 바닥 그림자 · 크기 · 위치) **네 판단을 먼저 `design_notes.md` 13라운드에 적고** 반영해라. 도트를 새로 그리거나 화풍을 바꾸는 것은 하지 말 것(그렇게 하고 싶다면 이유만 적고 하지는 마라).
- 방향: 도트는 왼쪽을 본다. 오리는 미야코 **왼쪽**에 있으므로 미야코 쪽(오른쪽)을 보게 좌우 반전할지 네가 장면에서 판단해 정해라.
- 기존 오리의 호흡 · 살짝 까딱이는 움직임 수준의 느린 모션은 유지(도트라 부위 분리는 하지 않고 전체를 위아래로 아주 조금 + 미세 기울기 정도). 모션 줄이기 · 정지 처리 유지.
- 크기 · 위치는 마루군(오른쪽)과 균형이 맞게 조정(미야코보다 작게, 그림자 접지).
- 이 외 모든 것(미야코 v9, 마루군, 리츠 · 노노카 · 유노 · 아라레)은 그대로. 결과 = `birthday_bg_v10.html`(`assets5/build_v10.py`, v9 이하 보존). 도트 이미지는 `assets5/mallard_icon.png` 로 복사해 보존. 외부 요청 0 · 디스클레이머 유지.
- Chrome 으로 미야코 장면을 확대 캡처(`qa/shots13/`)해 직접 보고 어울리는지 평가, 아쉬운 점을 솔직히 보고.
