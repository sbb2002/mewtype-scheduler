  • 표시되는 정보는 멤버·공식 계정이 공개적으로 게시한 내용만을 정리한 것입니다.
  • Groq을 통해 AI 번역 서비스가 함께 제공됩니다. 만약 정확한 정보가 필요하시면 공식 채널을 통해 교차검증하시길 권장합니다.
  • 트윗은 X 공식 임베드로 표시되며 번역은 비공식 팬 번역입니다.
  • 서비스 개선을 위해 Vercel Web Analytics로 익명 방문 통계(방문 페이지·유입 경로·국가·기기 및 브라우저 종류)를 수집합니다. 쿠키를 사용하지 않으며 개인을 식별할 수 있는 정보는 저장하지 않습니다.
  • 삭제 요청이 있으면 예고 없이 서비스가 중단될 수 있습니다. 문의·삭제 요청은 GitHub Issues로 받습니다.
