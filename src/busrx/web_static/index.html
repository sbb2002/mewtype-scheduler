자동 수정 이력

파이프라인 조립

블록을 끼워 맞춰 자동 수정 파이프라인을 만듭니다. 🔒 잠금 블록(가드 · 보호 확인 등)은 빼거나 끄거나 순서를 바꿀 수 없습니다. 저장한 파이프라인은 제어 탭의 에러 레벨별 정책에서 고를 수 있습니다.

수신기 분석

정지하면 새 ERROR 이상 에러를 분석·수정하지 않고 기록만 합니다(rx/PAUSE).

발신기 발신

정지하면 CRITICAL 을 제외한 에러 봉투 발신이 멈춥니다.

발신 레벨

기본은 WARN. INFO · DEBUG · TRACE 는 지정한 시간이 지나면 자동으로 WARN 으로 돌아갑니다.

에러 레벨별 자동 대응

심각도마다 기록 · 분석 · 수정 파이프라인 시작 여부와 프리셋을 정합니다. 저장하면 다음 에러부터 바로 적용됩니다(재시작 불필요). WARN 이하는 “수정까지”를 선택할 수 없습니다.

레벨기록동작파이프라인쿨다운(분)
자동제어 설정 초기화

에러 레벨별 정책을 기본값(CRITICAL 긴급 수정 · ERROR 표준 수정 · WARN 이하 끔)으로 되돌리고, 사용자 정의 파이프라인을 모두 지워 내장 프리셋(표준 · 긴급)만 남깁니다. 수신기 정지(PAUSE) · 발신 레벨 같은 일시 설정은 건드리지 않습니다.
