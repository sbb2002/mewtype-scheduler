🤖 자동제어 관리

구독 사용량
아직 측정값 없음 — “지금 조회”를 누르거나 첫 분석 뒤에 표시됩니다.

헬스체크

버스 큐 발신기 → 수신기 사이 폴더 대기열

패치 정책 읽기 전용

수정은 로컬 브랜치에만 커밋되고 main · data 브랜치와 배포 주소에는 닿지 않습니다. 변경은 설정 파일(.env.local)에서만 합니다.

모델 역할 할당

파이프라인 조립

수정 파이프라인을 블록으로 조립합니다. 🔒 잠금 블록(가드 · 보호 확인 등)은 빼거나 끄거나 순서를 바꿀 수 없습니다. 저장한 파이프라인은 아래 “로그 레벨별 대응 정책”에서 고를 수 있습니다.

동작 모드

자동제어가 에러에 어떻게 반응할지 정하는 전체 스위치입니다.

동작 주기

수신기가 쌓인 에러를 언제 처리할지 정합니다. 동작 모드가 자동 또는 반자동일 때만 적용되며, CRITICAL 은 주기와 관계없이 즉시 처리합니다.

로그 레벨별 대응 정책

심각도마다 러너가 발신할지, 수신기가 기록 · 분석 · 수정을 어디까지 할지, 파이프라인과 쿨다운을 정합니다. 저장하면 다음 에러부터 바로 적용됩니다(재시작 불필요).

레벨발신(러너)기록동작파이프라인쿨다운(분)

설정 및 정책 초기화

에러 레벨별 정책과 동작 주기를 기본값(CRITICAL 긴급 수정 · ERROR 표준 수정 · WARN 이하 끔 · 이벤트마다)으로 되돌리고, 사용자 정의 파이프라인을 모두 지워 내장 프리셋(표준 · 긴급)만 남깁니다. 수신기 정지(PAUSE) · 임시 발신 레벨 같은 일시 설정은 건드리지 않습니다.

대기 중인 에러가 있습니다

“예”는 쌓인 에러를 지금 처리한 뒤 모드를 바꾸고, “아니오”는 쌓인 에러를 버리고 모드를 바꿉니다. “취소”는 아무것도 바꾸지 않고 창만 닫습니다.
