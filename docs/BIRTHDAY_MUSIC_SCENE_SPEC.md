## 2. 장면 (시안과 동일해야 함)

시안 코드의 효과를 그대로 이식한다(같은 수식 · 같은 상수). 확정된 효과:
halo(박 버스트 · 첨도 · 무작위 각도 · 파형) · LED horizon(곡 구간별) · 바닥 격자 + 발광 띠(볼록) · 유성 이벤트 · 쇼크웨이브 · 오로라 · UFO1(지그재그 / **유노 사인** 랜덤) · UFO2(정지 스캔) · 유노 DJ 동작(곡 구조별 변주) · 노란 별.

시안과 달라지는 점(운영자 확정):
1. **유노는 어느 기기든 화면 가로 정중앙**. 시안의 유노 · 데크 x=675 를 **x=600**(장면 중앙)으로 옮기고, 카메라 중심을 항상 유노(x=600)에 둔다. 화면이 좁아지면 양옆이 먼저 잘린다.
2. **드롭 기준 시각**: 곡 1(Noctural Run)의 첫 드럼 = **17.14초**(저음 40~130Hz 에너지 +40dB 점프로 측정). 시안은 8박 블록 기준 18.46초를 썼다 → 쇼크웨이브 · 구간 판정(`drop`)의 곡 1 값을 17.14초에 맞춘다(곡 2 는 14.52초 유지).
3. 장면 시계는 `audio.currentTime` 기반(시안의 `curTime`/`LAT=0.02` 평활화 로직 유지).

## 3. 인트로 (첫 접속, 생일 당일)

곡 시계 기준(벽시계 아님):

| 시각 | 밝기(장면 전체에 곱함) | 기타 |
|---|---|---|
| 0s | 0.03 | 암전. Noctural Run 재생 시작(볼륨 0.3). 유리 패널 · 🎂 · 플레이어 숨김 |
| 0 → 3s | 0.03 → **0.30** | ease-out. 유노 · 데크 · 태양이 또렷이 보이는 어두운 밤. 이후 17s 까지 0.30 유지(±1% 숨쉬기) |
| **17.14s** | 즉시 **2.4배** | 태양에서 동심원 3겹(분홍 · 보라 · 시안, 반지름 100→600px, 0.55초). 흰색 풀스크린 플래시 금지(장면 색을 그대로 밝힘). 번쩍임은 1회 |
| 17.14 → 18.64s | 2.4 → **1.0** | **1.5초**에 걸쳐 ease-out 으로 평소 밝기 복귀 |
| ~19s 이후 | 1.0 | 컨트롤 · 제목 · 디스클레이머 순차 페이드인(컨트롤 0.6초 뒤 아래서 떠오름, 디스클레이머가 가장 늦게), 인사말 「Happy Birthday.」는 잠시 뒤 퇴장 |

- 장면 로직은 밝기 램프가 0.03 이어도 **계속 동작**(실루엣이 보이도록 애니메이션 정지 금지). 장면은 곡 1 의 17.14초 이전 구간(인트로 구간)의 연출을 그대로 사용.
- 공개 시점은 곡 시계에 고정 → 자동재생이 막혀 탭으로 시작해도 항상 음악과 맞는다(탭 = 곡 0초부터 재생 + 인트로 시작).
- **자동재생 정책**: `audio.play()` 시도. 성공하면 위 흐름. 막히면(`NotAllowedError`) 암전 화면 가운데에 「탭하여 시작 ♪」 한 줄만 표시(펄스), **첫 사용자 조작에서** 재생 + 인트로를 0초부터 시작.
- `prefers-reduced-motion`: 밝기 램프는 단순 페이드(번쩍임 · 링 생략), 장면은 정지 프레임(`setStill`).
- 이후 전환: 곡이 끝나면 다음 곡 + 제목 교체 + 장면 박 지도 교체. 곡 2 에서는 인트로 연출 없음.
- 두 번째 방문 이후에도 같은 인트로(저장하지 않음 — 기존 자동 온전히 보기와 같은 방식).

## 4. 플레이어 UI (시안 `plan_mockup.html` 의 PC · 모바일 탭을 기준으로 맞출 것)

- **하단 컨트롤**: 유리 알약(반투명 + blur, 마우스 호버 중 불투명) = 왼쪽 이동 손잡이 · 이전곡 · 재생/일시정지(핑크 원형) · 다음곡 · 음소거 아이콘 + 볼륨 슬라이더(PC). 모바일은 슬라이더 없음(음소거 토글만; iOS 는 `audio.volume` 이 고정이라 GainNode 로 30%).
- **우하단 곡 제목**: 형식 `♪BGM [mp3 제목]`, 재생 중 이퀄라이저 막대 4개. 모바일은 컨트롤 바로 위 우측. 제목 = 파일명 그대로(`Noctural Run`, `Midnight Groove`).
- **하단 디스클레이머**: `듣고 계시는 이 음악은 SUNO로 제작되었습니다.` 화면 최하단 중앙 한 줄(저대비, 가장 늦게 페이드인). 이스터에그 화면(온전히 보기)에서만 표시, 기존 푸터 디스클레이머와 별개.
- 컨트롤은 **온전히 보기(이스터에그 화면)에서 표시**. 일반 화면(유리 패널)에서는 음악이 계속 재생되며(번갈아 연속), 일반 화면의 작은 재생/정지 아이콘은 제거한다(2026-11-01 운영자 수정). 재생 조작은 생일 전체 화면 컨트롤에서만 한다.
- 볼륨 기본 **0.3**, 슬라이더 값은 `localStorage` 키 `bday-vol`(생일 스킨 날에만). 생일 전체 화면의 키보드: Space 재생/정지 · ←/→ 이전/다음 · ↑/↓ 볼륨 · M 음소거.
- 마이크로인터랙션(시안에서 동작 확인 가능): 호버 확대 · 눌림 축소 · 물결(ripple) · 재생/정지 아이콘 전환 · 이전/다음 화살표 3px 밀림 + 제목 올라오며 교체 · 볼륨 핸들 확대/후광 + % 말풍선 · 0 이면 🔇 · 5초 무입력 시 컨트롤 투명도 55% · 모바일 가벼운 진동(`navigator.vibrate`) · 접근성 `aria-label` · 포커스 링.
- 🎂 버튼(`birthdayui.js`)은 기존 동작(꾹 누르기 끌기 · 위치 저장) 유지. 플레이어 영역을 피하도록 `limits()` 확장.

## 6. 복사 방지 (완벽 불가 — 한계를 문서에 적을 것)

1. **사인은 이미지 파일이 아니다**: 벡터 좌표만 `bdaysign.js` 에 두고 항상 Canvas 로 합성. `<img>` · 별도 파일 요청 없음. 좌표는 평문 배열이 아닌 인코딩 문자열 + 디코드 함수.
2. 장면 · 컨트롤 영역: `contextmenu` 차단, `draggable=false`, `user-select:none`, `-webkit-touch-callout:none`, 이미지에 `pointer-events:none`.
3. 장면 캔버스의 `toDataURL` · `toBlob` · `getImageData` 를 빈 값으로 무력화(이스터에그 화면 동안만, 해제 시 복구).
4. 이스터에그 화면에서 F12 · Ctrl+Shift+I/J/C · Ctrl+U · Ctrl+S 가로채기(약한 억제).
5. 사인은 UFO 가 그린 뒤 5.5초만 표시.
6. mp3 는 재생을 위해 내려받아야 하므로 막을 수 없음(파일명 난수화 정도). 개발자 도구 · 화면 캡처까지 막는다고 주장하지 말 것 — `docs/SPEC.md` 에 「우연한 가져가기를 어렵게 하는 장벽」으로 정직하게 기록.

## 7. 성능 · 접근성 · 정리

- 장면 프레임 CPU 비용 **8ms 이하**(1장면 기준, 시안은 2카드 합 22ms 이내였음). 숨은 탭 렌더 정지, 화면 밖 정지, 곡 시계 평활화.
- `destroy()` 후 이벤트 리스너 · `requestAnimationFrame` · `Audio` · `AudioContext` · blob URL 0. 자정 전환(`evaluate`)에서도 동일.
- 모든 컨트롤 `aria-label`, `prefers-reduced-motion` 존중.
- 음원 로드: 첫 곡은 스트리밍으로 즉시 시작, 다음 곡 선로딩(blob 로 받아 임의 탐색 정확하게 — 시안에서 Range 미지원으로 탐색이 0초로 돌아가던 문제를 이 방식으로 해결함). 음원 약 10MB 는 원본 유지(용량 축소는 하지 않음).
