    동작

    • 접힘(기본) — 딱 한 줄. 5초마다 다음 소식으로 세로 슬라이드, 끝나면 처음부터 무한 순환. 진행바 없음.
    • 마우스 올리면 정지(읽기·클릭), 벗어나면 재개. 펼치기(▾) → 전체, 접으면 마지막 보던 소식부터 재개.
    • 좌측 램프 — TODAY 배지가 하나라도 있으면 빨간색 느린 점멸, 없으면 소등 유지. (상단 "램프 시뮬" 버튼으로 미리보기)
    • 모바일 동일. 시간 칸 축소 + 출처는 아이콘만.

    내용 · 수명

    • 한 줄 = [날짜/시간] [TODAY/D-n] [이름·marquee] [출처]. 모든 컬럼 고정 폭(이름만 가변). 시각은 KST 와 같아 변환 안 함.
    • 이름 클릭 → 트윗이 준 URL(YouTube/bilibili/스토어…). 출처 = PC 는 [아이콘] @ID, 모바일은 [아이콘]만. 클릭 → 원문 트윗.
    • 시간 앞 아이콘 = 이름 클릭 시 도착할 사이트. 임박순 정렬, 카테고리 4개.
    • 수명 — 각 소식은 그 날짜 자정(JST=KST)까지 표시 후 사라지고 notice_archive.json 에 보존. 아래 스케줄과 중복 제외.
