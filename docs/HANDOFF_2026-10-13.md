- **보류(운영자 결정, 2026-10-13)**:
  - RSS 관련 개선(PubSub 도입 · `playlistItems` 폴백 등) — 한국 시간 낮(08~16시)에만 RSS 가 막히는 규칙성이 확인됐고, 지켜보기로 함. 새 개선을 먼저 제안·진행하지 말 것.
  - 테스트판의 main 병합·배포 — 검증 전 코드를 배포판과 공유하지 않는다. (충돌 우려 파일: `telegram_app.py` · `llm.py`, `docs/` 25개 — main 은 docs 4개 규칙)
  - 외부 API 공급자 교체(예: Groq 유료 전환)의 자동화 — 수동 패치로 한다.
