# 배경 보기 해금 시나리오 · 조작 패널 (bg-dome HUD 구현 계획)

2026-11-09. 운영자 초안(첫 실행 · 우주 · 딥필드 해금)을 뼈대로 Claude · Codex · agy 가 빈칸을 채운 합의안 + 운영자 결정 · 코멘트(같은 날 두 차례).
**구현 전 계획이다.** 「추후 논의」 · 「시안으로 정함」이 남은 곳은 정해지기 전에 구현하지 않는다.
HUD 시안 = `ref/bg-dome/hud/hud_f5.html`(F5), 시안 이력 · 합의 근거 = `ref/bg-dome/hud/HUD_IDEAS.md`. 코드 사실은 `feat/bg-dome` `193d68f` 기준.

용어(이 문서에서 쓰는 것):
- **해금** = 하늘(배경)이나 기능이 처음으로 쓸 수 있게 열리는 것. 기기에만 저장(localStorage).
- **기본 우주** = 지금의 초행성X 하늘(별 지도 · ESO 은하수 · 그려 만든 우주 중 무작위).
- **딥필드** = 우주 사진이 보이는 우주 하늘. 지금 코드의 사진 목록(`bgdomegl.js` `DEEP_SET`) 중 지구돋이를 뺀 다섯 — SMACS 0723 딥필드 · 게 성운 · 오리온 성운 · 창조의 기둥 · 타란툴라 성운.
- **달 궤도** = 지구돋이 사진(`space-earthrise.webp`, 달 궤도에서 본 지구) 하늘. 딥필드와 따로 다루는 마지막 워프 도착지.
- **워프 목적지 고르기** = WARP 버튼을 누를 때 뜨는 도착지 선택 창.

## 바탕 설정

UFO 가 분홍 구름 속(버츄얼 스페이스)에 떠 있다가, 하늘에서 표식을 찾아 외우주로 「가출」하고, 워프로 딥필드를 떠돌다 마지막에 달 궤도에서 돌아갈 곳(지구)을 찾는다.

## 첫 실행

- 하늘은 **버츄얼 스페이스**만.
- 조작 패널의 **초행성X로의 여행 · 지구** 칸은 잠김. 잠긴 칸 설명 자리에 다음 행동 한 줄(아래 「힌트」).
- **우주 진입 10% 무작위 성간 이동은 끈다**(운영자 11-09 — 지금 `bgdomegl.js` `STAR_RATE` 0.1). 성간 이동은 길게 누르기로만 시작한다.

## 해금 단계

| 단계 | 어디서 | 하는 일 | 열리는 것 |
|---|---|---|---|
| 1 | 버츄얼 스페이스 | **토성 표식** 찾기 — 조작 패널 초행성X 칸의 토성 아이콘과 같은 모양, 구름 위에 떠 있는 「외우주행 표식」 | **초행성X(기본 우주)**. 성간 이동은 아직 잠김 |
| 2 | 기본 우주 | **성운**(빛 무리) 하나 찾기 | 초행성X 칸 **길게 누르기 = 성간 이동** |
| 3 | 성간 이동 | WARP 로 **무작위 딥필드**에 도착 — 도착한 딥필드가 하나씩 **워프 목적지 고르기**에 추가 | 딥필드(다섯 개, 하나씩) |
| 4 | 성간 이동 | 딥필드 다섯 개를 모두 가 본 뒤 **무작위 워프를 한 번 더** 하면 달 궤도에 도착 | **달 궤도** |
| 5 | 달 궤도 | **지구** 찾기 | **지구 테마**(마지막 해금) → 마지막 보상 |

- 단계마다 상징적 발견이나 이동 하나로 열린다. 모으기 숫자 · 도감 없음.
- 2단계 성운은 성간 이동만 연다. 딥필드는 무작위 워프로만 하나씩 열린다(운영자 11-09 확인).
- 대상 위치 · 허용 각도는 F5 시안 값이 예시다. 실제 배치는 구현 때 정한다.

## 멤버 탄생 별자리 — 별빛 조명 (운영자 11-09)

실제 하늘(지구)의 별자리는 계절 · 위도에 묶여 다 찾는 데 1년이 걸리므로 쓰지 않는다. 대신 **우주 테마(기본 우주)**에 멤버 생일의 별자리 5개를 둔다 — 가상의 하늘이라 계절과 무관하게 언제든 다 찾을 수 있다.

| 멤버 | 생일(`config.js` `BIRTHDAYS`) | 별자리 |
|---|---|---|
| 나카마치 아라레 | 08-16 | 사자자리 |
| 센고쿠 유노 | 11-04 | 전갈자리 |
| 미야나가 노노카 | 04-17 | 양자리 |
| 미네츠키 리츠 | 02-07 | 물병자리 |
| 후지 미야코 | 09-19 | 처녀자리 |

- 탄생 별자리 = 생일이 속한 황도 12궁(일반적인 날짜 구분 기준). 다섯 날짜 모두 경계일에서 떨어져 있어 출처마다 갈리지 않는다.
- 다섯 개를 모두 찾으면 **별빛 조명** 해금(멤버 5색 조작대 조명, 켜고 끄기). 찾는 순서 자유, 1단계(기본 우주 해금) 뒤 언제든.
- 찾은 별자리는 기본 우주 하늘에 선이 남는다(예시 — 시안으로 정함).
- 별자리 모양 · 별 위치 자료 출처(공개 자료만)는 구현 때 확인.

## 조작 패널 — 초행성X로의 여행 칸

| 상태 | 누르기(탭) | 길게 누르기 |
|---|---|---|
| 잠김(1단계 전) | 반응 없음 + 힌트 문구 | 없음 |
| 해금 · 2단계 전 | 기본 우주로 전환 | **반응하지 않는다**(탭과 같게 처리, 충전 표시 없음) |
| 2단계 뒤 | 기본 우주로 전환 | 1초 충전 → **성간 이동**(지금과 같음 — 워프 기어 N ~ 5단 · 레드존 · 경보) |

- **길게 누르기를 알려 주기**: 2단계 뒤 조작 패널을 처음 열 때 초행성X 칸에 「길게 눌러 성간 이동」 안내(칸 칩 문구 + 한 번 반짝임). 한 번 길게 누르면 안내는 사라진다.

## 성간 이동 — 워프 목적지 고르기 (운영자 11-09)

- **때**: 지금 코드에서 워프가 활성화되는 시점 = **WARP 버튼을 쓸 수 있게 될 때** — 레드존(β ≥ 0.85, 4 · 5단)이고 좌석벨트 표시등이 꺼져 있을 때(`bgwarp.js` `warpReady`, 운영자 11-06). 지금은 WARP 를 누르면 곧바로 점프(A · B · C 무작위)하고, 도착 순간 하늘 방향 무작위 + 지금과 다른 사진(`pickOtherDeep`, 지구돋이 포함)으로 바뀐다.
- **바뀌는 것**: WARP 를 누르면 **목적지 고르기** 창이 뜬다(가 본 딥필드가 하나라도 있을 때). 고르면 그곳으로 점프.
  - **고르지 않거나 취소하면 아무 일도 일어나지 않는다**(점프 없음, 성간 이동은 그대로).
  - 선택지 = **무작위** + 지금까지 무작위로 도착했던 딥필드들. 딥필드에 있을 때는 **「기본 우주로」**도 붙는다.
  - 가 본 딥필드가 하나도 없으면 창 없이 바로 무작위 점프(처음).
- **무작위 점프**: 달 궤도를 뺀 딥필드 중 무작위. 도착한 딥필드는 선택지에 추가된다.
  다섯 개를 모두 가 본 뒤의 무작위 점프 한 번 = **달 궤도**로 도착하고, 이때 달 궤도가 해금되어 선택지에 들어간다.
- 무작위는 **이미 가 본 딥필드도 다시 나온다**(운영자 11-09). 다섯 곳을 다 가 보는 데 평균 약 11번 점프(예시 계산, 지금 있는 곳을 빼고 고르는 지금 코드면 조금 줄어든다).

## 지구

- 달 궤도에서 지구를 찾으면 해금. **위치 권한은 해금 순간이 아니라 지구 칸을 처음 누를 때** 용도를 짧게 알리고 묻는다.
- 거부 · 오류여도 해금 기록은 남는다. 지구 칸에 「위치가 필요해요」 + 다시 시도, 다른 하늘은 계속 쓸 수 있다.

## 모두 열기 — 모니터링 페이지 지뢰찾기 (운영자 11-09)

기기를 바꾸거나 데이터가 지워졌을 때의 복구 수단.

- **진입**: 모니터링 페이지(`monitor.html`)의 숨은 입력(초기화 확인창을 바깥으로 밀어내기 ↑↑↓↓←→←→, `monitorbirthdaylogic.js` `MONITOR_BIRTHDAY_CODE`)에서 **방향 8개를 입력한 직후**.
- **유지**: 방향 뒤 **B · A**(코드의 `EXT` · `APP`)까지 넣으면 지금처럼 생일 이스터에그로 간다(추후 멤버별 이스터에그 고르기 창으로 바꿀 예정 — 운영자).
- **바뀌는 것**: 전체 추이 **잔디 그리드**가 **5 × 7 붉은 버튼**의 지뢰찾기가 된다. 지뢰 3개, 위치 무작위.
- **규칙(운영자 11-09, 일반 지뢰찾기 규칙을 웹에서 확인해 맞춤 — 아래 「참고한 지뢰찾기 규칙」)**:
  - **첫 탭은 늘 안전**: 지뢰는 첫 탭 뒤에 그 칸을 빼고 무작위로 놓는다(일반 관례).
  - **누르기(탭)**: 지뢰면 터진다. 아니면 둘레 8칸의 지뢰 수를 보여 주고, 둘레에 지뢰가 없으면 **빈칸**.
  - **빈칸 연쇄**: 빈칸이 열리면 이어진 빈칸이 연쇄적으로 모두 열리고, 그 빈칸 영역에 닿은 **숫자 칸도 함께** 열린다(일반 규칙 — 운영자 11-09).
  - **길게 누르기 = 깃발**: 깃발을 꽂은 칸은 탭이 먹지 않는다. 다시 길게 누르면 깃발 해제. 이미 열린 칸에는 꽂을 수 없다.
  - **깃발은 3개까지**: 3개를 꽂은 뒤 새로 꽂으려면 하나를 먼저 뺀다. 남은 깃발 수(3 − 꽂은 수)만 보여 준다.
  - **맞았는지는 숨긴다**: 깃발 3개가 모두 지뢰에 꽂히기 전까지 어느 깃발이 맞는지 · 틀렸는지 **어떤 표시도 하지 않는다**. 3개를 다 꽂았는데 하나라도 틀렸으면 아무 일도 일어나지 않고 게임이 이어진다.
  - **성공 = 깃발 3개가 모두 지뢰 위**: 테마 관련 이스터에그가 **모두 해금**되고 안내 메시지 창이 뜬다. (지뢰 아닌 칸을 다 열어도 성공이 아니다 — 일반 규칙과 다른 점, 운영자 「지뢰 3개를 표시」)
  - **지뢰를 누르면 폭발 효과** → 끝나면 **처음 화면으로 되돌아간다**(잔디 그리드 복귀). 다시 하려면 숨은 입력을 처음부터 다시 넣는다.
- **구현 확인(11-09, 코드)**:
  - 잔디 그리드 = 모니터 리포트(`src/backend/monitor_report.py`)가 그리는 **달력 SVG**(`#grassCalSvg`) — 가로 7칸(일 ~ 토) × 세로 4 ~ 6주. 5 × 7 은 5주짜리 달과 같은 모양이고, 4 · 6주 달은 그리드를 5 × 7 로 바꿔 그린다.
  - 리포트는 `monitor.html` 의 iframe 에 `srcdoc` 으로 들어가고 `sandbox` 가 없어 **바깥 페이지와 같은 출처**다 — 바깥에서 `contentDocument` 로 바꿀 수 있다. 지금 생일 이스터에그(`monitorbirthday.js`)도 같은 방식으로 iframe 안을 만진다.
  - **주의**: 리포트는 스스로 주기적으로 DOM 을 다시 그린다(`monitor.html` 주석 v3.8.7, 30분 안전망 전체 재로딩 포함). 지뢰찾기 중에는 그 다시 그리기가 판을 덮어쓰지 않게 막아야 한다.
- 노노카 이스터에그는 고려하지 않는다. 해금 목록을 무엇으로 관리할지(JSON 파일 등)는 **아직 정하지 않는다**(운영자).
- **참고한 지뢰찾기 규칙**(웹, 11-09): 일반 규칙은 지뢰 아닌 칸을 다 열면 이기고 깃발은 필수가 아니다 · 첫 클릭은 안전하게 지뢰를 첫 클릭 뒤에 놓는 구현이 많다 · 0 칸을 누르면 이어진 0 칸과 그 테두리 숫자 칸이 한꺼번에 열린다 · 깃발 카운터 = 지뢰 수 − 꽂은 깃발 수(틀린 깃발도 깎인다).

## 힌트

- 잠긴 칸 설명 자리에 다음 행동 한 줄 — 예: 초행성X 「구름 속 토성을 찾아봐」, 지구 「우주에서 귀환 신호 수신 중」(문구는 예시).
- 토성 표식은 처음 보는 방향 가까이(예시 ±25°). HUD 방위 테이프의 분홍 점 = 못 찾은 대상 방향(F5 그대로).
- 첫 시선 링이 뜰 때 한 번만 「잠시 바라보기」.

## 지키는 원칙 (세 의견 공통)

- 해금을 **방송 · 라이브 · 생일 시각과 묶지 않는다**. 방송으로 나가는 길은 언제나 막히지 않는다.
- 이미 3하늘을 쓰던 사용자는 다시 잠그지 않는다(조작 패널 기억 `bgindoor` 등으로 판별 — 판별 방법은 구현 때 확인).
- PC 는 조작 패널을 띄울 방법이 생기기 전까지 잠금을 적용하지 않는다.
- 자동 출발 워프 없음, 라이브 중에만 잡히는 대상 · 일일 과제 · 실패 벌칙 · 진행 초기화 버튼 없음.
