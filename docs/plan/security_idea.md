# idea1. 하드웨어 UUID + MAC 주소 등록제
- 고유로컬번호 = (하드웨어 UUID + MAC주소)
- 관리자 비밀번호 = 고유로컬번호가 등록되지 않은 곳으로부터 배포, 수동 데이터 쓰기 작업 시도 시 맞춰야만 하는 비밀번호 또는 그런걸 담은 파일.
- 이제부터 배포 및 수동 데이터 쓰기 작업 시 고유로컬번호가 등록되어 있어야 함. 이건 깃허브에 저장하지 않되 기억해야함.
- 배포 및 수동 데이터 쓰기 작업 시 고유로컬번호 등록되어있지 않으면 DM으로 작업시도자의 고유로컬번호, 시도하려는 작업, 시도 시각을 알려주고 관리자 비밀번호를 물어봄.
- DM으로 비밀번호나 비밀파일을 주지 않으면 해당 작업은 취소됨. 
- 시도작업이 성공/실패 여부 상관없이 시도자의 고유로컬번호, 시도작업, 시도시각, 시도결과를 기록할 것.
