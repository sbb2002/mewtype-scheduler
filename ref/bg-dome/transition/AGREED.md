# 하늘 전환 「돔 재투영」 — Claude · Codex 합의안 (2026-11-06, 운영자 승인 전)

운영자 요청: 조작 패널에서 하늘을 바꿀 때 지금의 부드러운 걷기(View Transitions 마스크)는 「세련되지 않다 — 사이버펑크 · 버츄얼 · 미래지향 · 홀로그램 특성을 못 살렸다」.

## 한 줄
돔을 「투영 스크린」으로 보고, 천정에서 시작한 **곡선 스캔 경계가 돔을 따라 내려오며 새 하늘을 다시 맺는다**. 경계 근처에서만 고정 점무늬(디더)로 영상이 교체되고, 시안 진행 선 · 분홍 잔광. 패널은 그동안 「송신 중」으로 옅어진다.

## 근거로 삼은 흐름
- 게임식 홀로그래픽 UI(빛으로 투사된 조작 화면) — 전환을 「패널이 돔 투영 장치를 작동시킨 결과」로 보인다.
- 복고 미래주의 — 낡은 모니터 흉내가 아니라, 영상이 완성되는 순간에만 작은 점 · 색 어긋남.
- 사이트 고유의 효과 문법 — 패널 등장의 「광선 → 표면 형성 → 색 어긋남 → 안정」을 공간 규모로 확장.

## 타임라인 (사진 · 위치 준비가 끝난 뒤 기준)
| 단계 | 시간 | 보이는 것 |
|---|---:|---|
| 선택 | 누른 즉시 | 칸 선택 표시 · 8ms 진동 1회(같은 칸 재선택은 없음). 준비가 필요하면 「불러오는 중…」, 하늘은 그대로 |
| 송신 시작 | 0~80ms | 패널 판 0.35 · 칸 배경 0.12~0.18 · 글자 1, 뒤 흐림 끔. 천정 이음선에 시안 선이 맺힘 |
| 재투영 | 0~900ms | 위도를 따라 휘는 경계가 천정 → 돔 가장자리로 하강(경도 칸마다 15~25ms 차이). 경계 근처만 화면 좌표 4×4 Bayer 점무늬(칸 3 CSS px), 각 점은 한 번만 교체. 선택 칸 테두리에 시안 선이 같은 진행률로 지나감 |
| 정착 · 복귀 | 900~1100ms | 분홍 잔광이 사라짐. 마지막 120ms 에 패널 배경 복귀. 번쩍임 · 흔들림 없음 |
| 우주 출발 연결 | 1100ms 이후 | 초행성X 진입당 한 번 10% 판정 → 해당하면 기어 1단(3단계) |
| 단축 완료 | 시점 변화 합 6° 초과 · 두 손가락 줌 시작 · 화면 크기 변경 | 남은 옛 화면 · 빛을 최대 150ms 에 지움 |
| 움직임 줄이기 | 준비 즉시 | 바로 교체, 송신 효과 · 자동 성간 이동 없음 |

- 색: 진행 선 시안 `#4fe3ff`(중심에 크림 소량) · 잔광 분홍 `#ff6fb5`. 하늘 전체를 물들이지 않는다. 선 1~2px + 번짐 6~10px, 밝은 구름 위에서는 선 바로 앞을 살짝 어둡게.
- 경계는 돔과 무대 바닥이 만나는 고리에서 끝난다 — 바닥 · 조종대는 세 목적지 모두 같다(지구 장면도 같은 무대 바닥을 합성: `bgdomegl.js` 782행).
- 구현: 밝게/어둡게 전환의 「직전 화면 복사(copyTexImage2D) + 마지막 색 합성에서 섞기」를 재사용. 지속적인 추가 렌더 패스 없음(시작 순간 복사 1회).
- 밝게/어둡게 전환과의 구별: 그쪽은 칸들이 둘레 방향으로 차례로 바뀌는 「조명 변화」, 이쪽은 한 줄 곡선 경계가 내려오는 「영상 형성」.

## 이견 · 정리된 것
- (정리) Claude 의 「지구는 바닥까지 걷힘」은 철회 — 지구 장면도 무대 바닥 · 조종대가 남는 현재 구조와 어긋남(코드로 확인).
- (보류) 테마 팝업(기본 · UFO · 생일)까지 같은 언어로 바꾸는 것 — 규모가 다른 동작이고 UFO 특징이 다른 테마로 번진다. 지금 걷기를 유지하고, 돔 재투영을 폰에서 본 뒤 UFO 진입 · 이탈과 함께 검토.
- 3단계 메모: 우주 출발 시계 · 10% 판정은 `spaceT0`(첫 그리기)가 아니라 「우주 진입 전환 완료」에 연결. 지구 → 우주 복귀도 같은 기준.
