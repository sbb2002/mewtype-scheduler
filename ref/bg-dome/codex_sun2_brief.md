# 2차 수정 의뢰: 해 질 녘 해 — 아직 「작은 흰 점」이다. 금빛 글로우를 확실하게

같은 파일(`src/frontend/js/bgdomegl.js`, 셰이더 해 · 해 쪽 하늘 부분)만. bggyro.js · bgview.js 는 건드리지 말 것. git commit 금지.

Claude 가 네 1차 결과를 폰 크기(390×760, 실제 화면과 같은 바깥 보기 카메라 — 해를 겨누고 8° 아래를 향한 상태)로 캡처했다.
첨부 1 = `now_1710.png`(2026-11-04 17:10, 해 고도 3.2°), 첨부 2 = `now_1720.png`(17:20, 1.4°).

## 문제

1. 해가 **지름 몇 px 의 작은 흰 점**이다. 운영자 말: 「실제 태양은 지금 시간에 금빛으로 노란 글로우를 보이고 있어」. 지금은 글로우가 거의 안 보인다.
2. 해 질 녘 하늘이 금빛이 아니라 **옅은 라벤더 · 분홍**이다. 해 고도 12° ~ 0° 구간은 실제 낮(파랑) 이미지와 노을(장밋빛) 이미지가 섞이는데 그 결과가 탁한 라벤더가 된다. 해 질 녘 해 쪽 하늘은 금빛 · 호박빛으로 따뜻해야 한다.
3. 해가 배경과 따로 논다(운영자: 「배경 색깔과 전혀 어우러지지 않아」).

## 원하는 모습 (실사 · 골든아워 사진 기준)

- 해 원반: 따뜻한 흰금색 핵(완전한 흰색 아님) + 노란 · 금빛 테. 원반 크기는 지금(각반지름 1.2°) 정도 유지하되 블룸으로 실제보다 크고 밝아 보이게.
- **넓은 금빛 글로우**: 해 둘레 반경 수 도 ~ 20° 정도까지 노랑 → 금 → 호박색으로 서서히 옅어지는 밝은 번짐. 화면에서 확실히 보일 만큼(폰 화면 높이의 1/4 ~ 1/3 정도까지 따뜻해짐).
- 해 쪽 지평선 하늘 전체를 금빛 · 호박빛으로 물들이고, 해에서 멀어질수록(방위 · 고도) 이미지 원래 색(분홍 · 보라)으로 돌아가게. 반대편 하늘은 차갑게 남는다.
- 구름: 해 근처 구름 결이 금빛으로 빛나게(가장자리 하이라이트) — 구름 알파(skySet 의 a) 활용.
- 고도별: 15° 위로 갈수록 글로우 색이 노랑 → 흰빛으로, 크기 · 세기는 줄되 낮에도 은은한 광륜. 해 뜰 때(uDawn)는 같은 구조로 조금 더 옅은 복숭아 · 연금빛.
- 과노출 덩어리 · 띠(밴딩) 없이 부드럽게. 톤 매핑으로 흰색으로 날아가지 않게.

## 제약 · 확인

- 성능: 반복 · 텍스처 추가 없이(지금 + 15% 이내). 실내 보기 픽셀 차이 0 유지.
- 확인은 반드시 폰 크기(390×760)와 **이 카메라 조건**에서: bgtime 2026-11-04 17:00 · 17:10 · 17:20, 12:20, 2026-11-05 07:10. 해를 겨누는 방법 = `deviceorientationabsolute`(alpha = -방위, beta = 90 + 고도 + 8). 결과 캡처를 `_local/sun-review2/` 에, 1차와 나란히.
