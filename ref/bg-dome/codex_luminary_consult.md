## Claude 초안 (검토 · 반박해 달라)

1. **달 착시(moon illusion)는 광학이 아니라 지각 현상** — 사진 · 측정 각크기는 지평선에서도 같다(대기 굴절은 오히려 세로로 약간 납작하게 만든다, 이미 구현). 그래서 원반을 키우는 것은 「실제 크기 유지」와 충돌한다.
   → 원반은 그대로 두고, 착시를 부르는 **지각 단서**를 준다: (a) 지평선 근처에서 크기 비교 대상(돔 테두리 · 바닥 가장자리 · 지평선 실루엣)과 가까이 보이게(폰조 · 에빙하우스류 착시 — 효과 크기는 확실하지 않음), (b) 저고도에서 광륜(aureole) · 번짐 반경이 커짐(대기 질량이 늘어 전방 산란 증가 — 이건 물리적 근거 있음), (c) 밝기 저하 + 색 변화.
2. **색**: 대기 질량(airmass, 예: Kasten–Young 1989 근사식)과 레일리 산란(파장의 −4제곱)·에어로졸 소광으로 저고도일수록 노랑 → 주황 → 빨강, 밝기 감소. 고도별 색을 하드코딩 대신 소광 모델로 일관되게 낼 수 있는지.
3. **해의 쨍함**: 사람 눈 · 카메라의 눈부심 모형 — (a) 여러 폭 가우스 합의 블룸(점 확산 함수 근사), (b) 조리개 회절 빛줄기(날 수 N 이 짝수면 N 줄, 홀수면 2N 줄), (c) 렌즈 고스트 — 해의 화면 위치 s 와 기준점 c 를 잇는 직선 위 c + k·(s − c) (k < 0 여러 개)에 옅은 색 원 · 고리, (d) 해가 화면 중심에 가까울수록 눈부심 · 대비 저하(베일링 글레어)가 커짐 = 「시선에 따른 빛번짐」. 해가 화면 밖에 있어도 가장자리 근처면 번짐이 들어오게.
4. 성능: 한 패스 · 텍스처 추가 없이, 고스트는 해석식(반복 6 ~ 8회 이하). 지금 + 15% 이내.

## 답해 줄 것 (결과는 마크다운 한 문서로)

1. 위 초안의 과학적 사실 확인 · 정정(근거 · 확실도). 특히 달 착시를 「실제 크기 유지」로 표현하는 정직한 방법, 저고도 광륜 크기 변화의 물리적 근거, 소광 색 모델의 실용 근사식.
2. 해 · 달 각각의 구현 방법론 — 셰이더 구조(어디에 무엇을 더하는지), 고도별 파라미터 표(색 · 밝기 · 광륜 반경 · 빛줄기 · 고스트 세기), 시선 의존 효과 식.
3. 「실제 크기 유지」 원칙과 충돌하는 지점이 있으면 선택지와 추천(예: 원반은 실제, 광륜 · 번짐만 키움 / 지각 보정 배율을 아주 약하게 허용 등).
4. 위험 · 함정(과한 효과, 밴딩, 작은 원반이 몇 픽셀일 때 계단 · 반짝임, 실내 보기 영향 등)과 검증 방법(어떤 시각 · 방향으로 무엇을 캡처해 어떻게 판정할지).
5. 단계별 구현 순서 제안.
