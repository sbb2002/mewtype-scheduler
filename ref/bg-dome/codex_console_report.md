# UFO 바닥 제어 장치 디자인 변경 보고

작업일: 2026-11-06 · 워크트리: `feat/bg-dome`

## 1. 비교한 방향과 선택

- **크림색 비행접시 조종대 — 선택.** 가로로 둥근 크림색 외피와 티타늄 테, 별 항로 화면을 조합한다. 무대 렌즈 조명의 재질과 공중 별 장식을 이어 받으면서, 화면·버튼·받침으로 조종 장치의 용도를 드러낸다.
- **별 홀로그램 제단.** 떠 있는 별과 얇은 받침은 몽환적이지만, 공연 소품과 제어 장치를 구분하기 어렵고 기존 홀로그램 단말의 인상을 남길 수 있다.
- **파스텔 아케이드 단말.** 조작부가 명확하고 귀엽지만, 높은 캐비닛 실루엣이 공연장 시야를 가리고 일상적인 게임 기계에 가까워진다.

선택 이유: 배경에 이미 있는 크림색 렌즈·티타늄 테·라일락 빛을 재사용하는 것이 가장 자연스럽다. 낮고 넓은 실루엣으로 무대 중앙을 지나치게 가리지 않으면서 다가갈 대상을 만든다. 전체 사이트의 디자인 체계는 바꾸지 않고 이 장치에만 적용했다.

## 2. 바꾼 내용

### `src/frontend/js/bgconsole.js`

- `floorSvg()`: 청록색 점선 링과 퍼지는 네온 파동을 라일락 빛 웅덩이, 티타늄 받침 고리, 분홍색 유도 호 두 개, 앞쪽 크림색 짧은 호, 접지 그림자로 교체했다.
- `standSvg()`: 정면에서 본 둥근 비행접시형 외피, 금속 아래 테, 짧은 목과 넓은 발을 구성했다. 라일락 유리 화면에는 별·타원 항로·작은 계기를, 전면에는 분홍·크림·민트 버튼 세 개와 대기등을 배치했다. 청록 빛기둥·주사선·홀로그램 깜빡임은 제거했다.
- 크기: `FLOOR_HALF = 0.105`, `STAND_W = 0.16`, `STAND_VB = [0, 0, 160, 132]`. 발의 아래 끝은 기존 투영 코드가 가정하는 viewBox 아래 3단위 여백에 맞췄다.
- 색은 모두 콘솔 전용 CSS 변수로 연결했다. SVG 두 장의 전체 요소 수는 49개이며, 전부 `createElementNS`로 생성한다. 필터·SMIL·외부 이미지·라이브러리·글꼴을 추가하지 않았다.
- `quadMatrix()`부터 파일 끝까지 원본과 동일함을 검사했다. `createConsole().place`의 두 평면 구조와 반환 API를 유지했다.

### `src/frontend/css/bgpanel.css`의 바닥 콘솔 절

- `--bgcs-*` 색 변수 14개와 `:root[data-theme="light"] #bgdeco .bgcs` 재정의를 추가했다.
- 바닥 유도 호·항로의 작은 점·대기등만 같은 3.8초 주기로 `opacity: .45 → .95 → .45`를 반복한다. 본체와 별은 고정되어 형태가 안정적으로 보이도록 했다.
- `prefers-reduced-motion: reduce`에서는 반복 애니메이션과 콘솔 등장 transition을 끄고 대기 표시를 불투명도 `.8`로 고정한다. 기존 SVG 주사선·파동 애니메이션은 없어졌다.
- 화면 패널 절 이후 CSS는 원본과 동일하다. `bgpanel.js`, `.ufo-*` 규칙, `bgdomegl.js`는 수정하지 않았다.
- 두 소스 파일과 이 보고서는 UTF-8·LF로 저장했다.

## 3. 테마별 표현 의도

- **어두운 테마:** 따뜻한 크림색 외피(`#fff1dc → #d9cadc`)와 티타늄(`#a5a1bf`)이 짙은 무대에서 실루엣을 만든다. 화면은 짙은 자두·라일락(`#40334f → #756284`), 별은 렌즈와 같은 크림(`#fff0d7`), 바닥 빛은 라일락(`#b39ce8`)이다. 분홍 항로와 민트 버튼은 작은 포인트로만 쓴다.
- **밝은 테마:** 외피를 아이보리(`#fff7e9 → #e2d6e4`), 금속을 연한 보랏빛(`#b4a9c5`), 화면을 따뜻한 모브(`#58425f → #95768e`)로 바꾼다. 화면과 아래 테의 명암을 남겨 밝은 분홍 하늘에서도 외피·유리·금속이 구분되도록 설계했다.

위 내용은 코드의 색과 구조에 따른 표현 의도이며, 실제 렌더링 캡처로 확정한 시각 판정은 아니다.
