### 운영자 확정 사항(11-06) — 바꾸기 전 여기부터 확인
- **조작 패널 하늘 고르기**: 버츄얼 스페이스(분홍) · 초행성X(우주) · 지구(바깥, 위치 권한). 기기에 기억(`bgindoor` · `bgview`). 고른 뒤 준비 · 전환이 끝날 때까지 칸 비활성, 전환 중엔 패널이 0.15초에 꺼졌다가 끝나면 다가갔을 때와 같은 등장 연출로 다시 뜸.
- **하늘 전환 = 「돔 재투영」**(Claude · Codex 합의 → 운영자 조정): 도트(6px · 칸마다 고정 무작위 · 서서히 나타남)가 앞서고 **흰 띠(약 16px, 시안 글로우) = 「여기까지 완료」**가 뒤따름. 방향 3가지(위도 아래 · 위도 위 · 경도 반시계, 매번 무작위 · 바로 앞과 다르게), 늘 시야 밖에서 들어와 밖으로 나감. 1.4초 + 잔광 0.25초. 바닥은 점으로 깨지지 않게 부드럽게.
- **테마 팝업**(기본 · UFO · 생일): 위에서부터 걷히는 View Transitions(돔 재투영과 별개 — Codex 와 보류 합의). 시작 우선순위 생일 > 기억 > UFO.
- **성간 이동**: 우주 진입마다 10%(하늘 전환이 끝난 뒤 판정) + 초행성X 칸 1초 길게 누르기. N 에서 1.5초 뒤 자동 1단. 끝 = WARP 점프 · 우주를 떠남(하늘 바꾸기). **N 으로 멈춰도(v = 0) 끝나지 않는다**(운영자 11-06 — 전엔 N 정지 = 끝이었음, `stoppedAtN` 삭제). 옛 「1분 뒤 저절로 끝남」 없음.
- **워프 기어**: 화면 아래 컴팩트 스로틀(시안 B), 배경 보기 중 성간 이동 동안 늘. 하늘을 바꾸면 조작 패널과 함께 0.15초에 꺼짐, 그 밖의 끝은 흰 띠 + 도트로 사라짐.
- **WARP** = 레드존(β ≥ 0.85) + 좌석벨트 표시등 꺼짐에만. 점프 연출 A 섬광 돌파 · B 홀로그램 재투영(**멈칫 없이 급제동**) · C 터널 급제동, 같은 확률. 도착하면 하늘 방향 완전히 무작위 + 큰 사진을 다른 것으로.
- **N 으로 멈춰도 다른 곳**: 여행마다 무작위 축으로 달린 만큼 하늘이 돈다(전속 약 2.5°/초).
- **레드존**: 조작 · 기어 패널 테두리가 빨간 선 + 빨간 글로우. **5단 + 표시등 켜짐 = 경보**: 바닥 조명 붉게 맥동, 화면에 회전 경광등 + 붉은 가장자리, 경보 사이렌.
- **흔들림**: 표시등 켜짐 = 두 패널 빠르게 · 깜빡일 때 약하게, 돔 시선도 살짝. **진동** = 속도 변화율이 클수록 잦게(0.07 ~ 0.6초 간격), 거의 0 이면 없음, 도착 순간 쾅.
- **빛 궤적 수** = 속도 따라 N 0 · 1단 6 · 2단 12 · 3단 18 · 4단 26 · 5단 36(한 줄씩 서서히, 고정 순번), 번짐 두 겹 + 도플러 색(앞 청보라 · 뒤 주홍).
