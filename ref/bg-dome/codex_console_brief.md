# Codex 의뢰 — UFO 바닥 「제어 장치」(콘솔) 디자인 다시 하기 (2026-11-06)

작업 폴더 = 이 저장소 워크트리 `feat/bg-dome` (현재 폴더). 한국어로 보고해 줘.

## 무엇인가
팬 사이트(무겐다이 뮤타입 방송 예고판, 비공식 팬 메이드)의 배경은 **UFO 안의 공연 무대**다: 투명한 반구 돔(흰 격자) 너머로 분홍 하늘 · 구름, 발밑은 짙은 남보라 원판 무대(가운데서 바깥으로 #262337 → #101320, 밝은 테마 #3a344e → #202334)에 **티타늄 테 + 따뜻한 크림색 렌즈 조명 5개**(렌즈 #fff0d7, 빛 웅덩이 라일락 #b39ce8, 테 #a5a1bf)와 위로 뻗는 **부드러운 흰 빛기둥**. 공중에는 **파스텔 그라데이션 외곽선 장식**(별 · 고리 · 점 · 지그재그 · 반짝이, 색쌍 예: #ff8fbf→#ffc38a, #ffd36e→#9ee6a8, #8fe0d4→#8fb5ff, #a99bff→#ff9ed2)이 떠다닌다. 전체 분위기 = 몽환적 · 파스텔 · 아이돌 공연장 · 귀여운 SF.

폰에서 「배경 보기」를 열면 눈이 무대 중심에서 뒤로 물러나 있고(돔 반지름 1 기준 0.4), **무대 정중앙 바닥에 놓인 「제어 장치」**가 보인다. 두 손가락으로 다가가면(0.24 안쪽) 화면 가운데에 「UFO CONTROL」 조작 패널(별도 화면 UI, 이번 범위 아님)이 뜬다. 즉 이 장치는 「가까이 가 보고 싶은, 이 UFO 의 조종석 같은 물건」이어야 한다.

## 문제 (운영자 판정)
지금 장치(첨부 `console_v1_dark_light.png`, 왼쪽 어두운 테마 · 오른쪽 밝은 테마)는 **시안(청록)·남색 네온의 사이버펑크 단말**이라 위 테마 · 컨셉과 어울리지 않는다. 테마와 컨셉에 어울리게 다시 디자인해 줘. 디자인은 너에게 맡긴다 — 방향을 2 ~ 3 개 짧게 비교한 뒤 가장 좋은 하나를 **실제 코드로 구현**해 줘.

## 고칠 곳 / 고치지 말 곳
- 고칠 곳: `src/frontend/js/bgconsole.js` 의 그림(`floorSvg()` · `standSvg()` 와 크기 상수 `FLOOR_HALF` · `STAND_W` · `STAND_VB`), `src/frontend/css/bgpanel.css` 의 「바닥 콘솔」 절(`#bgdeco .bgcs*`).
- **고치지 말 곳**: 투영 방식(`quadMatrix` · `createConsole().place` 의 「바닥 평면 정사각형 1장 + 카메라를 향해 선 세로 판 1장」 구조, 반환 API), 화면 패널(`bgpanel.js` · `.ufo-*` 규칙), `bgdomegl.js`(셰이더 포함). 구조상 장치는 「바닥에 붙은 무늬 한 장 + 세로로 선 그림 한 장」으로 표현해야 한다 — 세로 판은 늘 카메라 쪽을 보므로 **정면에서 본 실루엣**으로 그리고, 바닥 판은 원근으로 눕혀진다.
- 테마: 밝은 테마는 `:root[data-theme="light"] #bgdeco ...` 로 값을 바꿀 수 있다(SVG 안 색은 CSS 변수나 class 로 빼면 테마 전환이 된다).

## 지켜야 할 것
- 모든 SVG 는 `createElementNS` 로 만든다 — `innerHTML` 금지(저장소 규칙). 외부 라이브러리 · 웹 글꼴 · 새 이미지 파일 금지(빌드 없음, 정적 호스팅). 공식 로고 · 캐릭터 · 그림 금지.
- 성능: 폰(S23 · 삼성 인터넷)에서 WebGL 배경 위에 얹힌다. 큰 면적 `filter`(blur 등) · 많은 요소는 피한다. 움직임은 SVG `animate` 나 CSS `transform` · `opacity` 위주로 가볍게. 이 SVG 들은 매 프레임 `transform: matrix3d(...)` 로 옮겨진다.
- `prefers-reduced-motion: reduce` 면 반복 움직임을 멈춘다(지금 규칙처럼).
- 거리 0.4 에서 화면 폭 390px 기준 대략 150 ~ 220px 폭으로 보이고, 다가가면 커진다 — 멀리서도 형태가 읽히고, 가까이서도 허술하지 않게.
- 「다가가면 뭔가 열린다」는 단서(은은한 맥동 · 대기 표시 등)는 유지하되 과하지 않게.
- 파일은 **LF 줄바꿈**으로 저장(CRLF 금지).
- 끝나면 `node src/frontend/js/bgconsole.selfcheck.mjs` 가 통과해야 한다.
