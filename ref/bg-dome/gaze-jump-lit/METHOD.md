## 1. 제안: 「멈췄을 때 재고, 움직일 때 반영하는 방위 오프셋」

> 화면 방위 = **상대 방위**(자력계 없음, 계단 없음) + **반영된 보정량**.
> 보정량의 목표값은 **폰이 멈춰 있을 때만** 갱신하고, 화면에는 **폰이 돌아가는 동안에만, 돌린 양에 비례해** 조금씩 반영한다.

이름(제안): **움직임 연동 방위 보정***
\* 움직임 연동 방위 보정 = 절대 방위와 상대 방위의 차이(보정량)를 화면에 섞되, 사용자가 폰을 돌리는 동안에만 돌린 양에 비례해 섞는 방식

## 2. 동작 정의

방위만 다룬다(라디안, `wrap` = −π~π 로 접기). 기호:
- `r` = 상대 방위(`RelativeOrientationSensor` 쿼터니언 → `forwardOfQuat` → 방위), `a` = 절대 방위(지금과 같은 `AbsoluteOrientationSensor`)
- `e` = 보정량 측정값 = `wrap(a − r)`, `ê` = 보정량 목표, `b` = 화면에 반영된 보정량
- 화면 방위 = `r + b` (+ 편각, 지금과 같음). 고도는 지금처럼 센서 고도 그대로

매 판독마다:
1. **정지 판정** — 상대 방위의 최근 회전 속도 `ω`(= `r` 의 변화량 ÷ 시간, 짧은 구간 평균)가 문턱 `ω_still` 아래면 정지. **절대 방위 변화는 판정에 쓰지 않는다**(계단을 「움직임」으로 오판해 그대로 통과시키게 된다 — Codex 지적).
2. **목표 갱신(정지일 때만)** — 정지가 `t_still` 이상 이어지면 `ê ← e` (짧은 구간 중앙값). 회전 중의 `e` 는 두 센서 시각 차로 틀어지므로 버린다(S19).
3. **반영(돌릴 때만)** — 이번 프레임 상대 방위 변화량 `|Δr|` 에 비례해 `b` 를 `ê` 쪽으로 옮긴다:
   `b ← b + clamp(wrap(ê − b), ± min(k · |Δr|, v_max · dt))`
   멈춰 있으면 `|Δr| ≈ 0` 이라 `b` 가 안 움직인다 → 화면이 혼자 움직이지 않는다. 돌리면 돌린 양의 `k` 배까지 보정이 섞인다(회전 이득 `1 ± k` — S18 의 개념).
4. **처음 · 재시작** — 첫 판독, 탭 복귀 · 센서 재시작(상대 방위 기준이 새로 잡힘)이면 `b ← e` 로 바로 맞춘다. 상대 방위의 기준은 임의라 이어 붙일 「이전 화면」이 없기 때문이다.
5. **대체 경로** — `RelativeOrientationSensor` 가 없거나 막히면(iOS 등) 지금 방식 그대로(절대 방위 + 0.08~0.44 초 감쇠).

지금의 화면 감쇠(`updateView` 0.08~0.44 초, 망원일수록 셈)는 손떨림 · 망원용이라 그대로 둔다 — 입력이 `a` 에서 `r + b` 로 바뀔 뿐이다.

### 이 방식이 남기는 것(받아들일 절충)

- **멈춰 있는 동안 생긴 차이는 다음에 돌릴 때까지 화면에 남는다.** 조건 「정지 불변」과 「수렴」이 부딪히는 자리이고, 정지 불변을 고른 것이다(S21 · S22 도 같은 선택).
  남는 크기 = 계단 크기(실측 최대 9.2°).
- 폰을 거의 안 돌리고 오래 보면 수렴하지 않는다. 대신 상대 방위가 어긋나는 속도도 느리다(얼마나 느린지는 이 폰에서 미측정).
- 계단이 「틀린 값」이었다면 다음 회전 때 틀린 쪽으로 맞춰진다. 지금도 바로 따라가므로 지금보다 나빠지지는 않는다.

## 3. 정해야 할 값 — 문헌에 폰용 수치가 없다

| 값 | 뜻 | 정하는 방법 |
|---|---|---|
| `ω_still` | 정지 판정 문턱 | 기록 CSV 에서 손떨림 구간(계단 시점 자이로 1~6°/초, 표시 4 만 11°/초)과 의도한 회전을 가르는 값 — 재생 시험 |
| `t_still` | 목표 갱신 전 정지 지속 | 계단이 정지 후 언제 오는지(REPORT: 멈춘 직후) 분포로 |
| `k` | 회전량 대비 보정 비율 | 재생 시험 + 운영자 폰 체감. S18 의 0.67~1.24 는 HMD 값이라 **상한 참고만** |
| `v_max` | 초당 보정 상한 | 재생 시험 + 체감 |

agy 의 수치(3°/초 · 12% · 0.5°/초)는 근거 확인이 안 돼 쓰지 않는다(`LITERATURE.md` 3장).

## 4. 실측 확인(이 문서 작성 때 한 것)

`../gaze-jump/data/20261112054143_g4wz.csv`(표시 11개 기록)에서:
- 상대 방위가 0.5° 미만으로 거의 그대로인데 절대 방위만 2° 넘게 뛴 표본 = 14회(최대 −9.2° · +9.1° · +8.6°). 그 순간 절대 방위의 **고도 변화는 모두 0.14° 이하**.
- 같은 시각에 가장 가까운 두 센서 판독의 고도 차 = 중앙값 0.04° · 95% 0.12° · 최대 1.15°.
→ 계단은 방위에만 있다. 고도는 고치지 않아도 된다.
