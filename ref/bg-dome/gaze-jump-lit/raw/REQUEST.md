# 참고문헌 조사 요청 — 「시선 튐」(2026-11-13, Claude 가 운영자 지시로 보냄)

## 현상 (폰 실측으로 확인된 사실)
- 웹 배경 「UFO 돔」은 폰 방향 센서로 화면 시선(카메라 방위)을 움직인다. 지금 코드는 W3C `AbsoluteOrientationSensor`(가속도 + 자이로 + 자력계 융합) 값을 0.08초 감쇠만 걸어 그대로 쓴다.
- 폰을 돌리다 멈춘 직후, 이 절대 방위 값이 표본 한 칸(약 17~34ms) 사이에 2.5~9.2° 계단처럼 뛴다. 같은 순간 자이로는 1~6°/초(손떨림 수준), `RelativeOrientationSensor`(자력계 없음)는 멈춰 있다.
- 결과: 사용자가 안 움직였는데 화면 시선이 0.2~0.3초 동안 혼자 움직인다. (운영자 폰 = 삼성 인터넷 30 / Chrome 143 기반)
- 자료: devpapers 브랜치 `ref/bg-dome/gaze-jump/REPORT.md` (`git show origin/devpapers:ref/bg-dome/gaze-jump/REPORT.md`)

## 문제 정의
절대 방위(정확하지만 계단이 있음)와 상대 방위(매끄럽지만 서서히 어긋남)가 있을 때, 그 차이(보정량)를 화면 방위에 언제 · 얼마나 섞을지 정하는 문제.
조건: (1) 폰이 멈춰 있으면 화면이 눈에 띄게 움직이지 않는다 (2) 돌리면 바로 따라온다 (3) 오래 두면 절대 방위에 맞춰진다.

## 찾아 줄 것
1. 이 현상(자력계 보정에 따른 방위 불연속 · 그것이 화면/시점 이동으로 보이는 문제)을 다룬 논문 · 특허 · 기술 문서 · 플랫폼 문서(Android/iOS/W3C/Chromium) · 공개 구현.
2. 보정을 사용자에게 안 보이게 반영하는 방법 — 예: 움직일 때만 보정, 속도 제한, 자기 교란 감지 후 차단, 지각 문턱(얼마나 움직여야 사람이 알아채나) 연구.
3. 웹 브라우저(특히 Android Chrome 계열)에서 이 센서들의 동작 · 알려진 버그.
