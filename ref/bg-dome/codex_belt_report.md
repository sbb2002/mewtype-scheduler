# 좌석벨트 표시등 조사 및 설계

조사일: 2026-11-06. 원본 `Gear.dc.html`은 읽기만 했다. 아래는 특정 기종 부품의 복제가 아닌 일반화한 PSU 표시등이다.

## 실물 자료와 비교

기종·항공사·객실 개조에 따라 달라지므로 기종 하나에 외관 하나를 단정하지 않는다. 사진으로 관찰한 외관과 기술 자료의 구조 설명을 구분했다.

| 대표 구성 | 하우징·렌즈 | 그림·점등 | 금연 표시와 배치 |
|---|---|---|---|
| 어두운 표시창의 픽토그램형 | 밝은 회색 객실 패널에 어두운 직사각형 창이 매립됨. 외곽은 완만한 모서리 | 호박색 벨트 양끝과 손, 버클, 삽입 화살표. 작은 창 안에 문장 없음 | 같은 PSU에 금연 그림을 나란히 배치한 사진 사례가 있음 |
| 밝은 객실에 통합한 소형 그림형 | 별도 금속 테두리를 강조하기보다 밝은 PSU 면에 작은 표시부를 통합 | 짧고 단순한 밝은 벨트 그림. A321T 객실 사진 사례에서는 금연 그림과 함께 보임 | 나란히 배치. 이 사진만으로 광원 종류와 꺼짐 색은 판단 불가 |
| 기존 전구 표지판 / LED 도광판형 | 특허는 기존 전구형 표지판을 LED·도광판 구조로 교체하는 방법을 설명 | 광원이 달라도 그림만 투과시키는 표시창으로 구현 가능. 이 자료만으로 색·픽토그램의 시대별 표준을 확정할 수 없음 | 특허에서 벨트와 금연 표지 용도를 모두 설명 |

첫째 외관은 [AeroTime 객실 사진](https://www.aerotime.aero/images/Fasten-seat-belt-sign.jpg), 둘째는 [A321T 객실 사진을 포함한 탑승 기록](https://www.aviationwithkrish.com/blog/a-unique-layout-american-airlines-flagship-business-class-on-the-a321t-from-san-francisco-to-new-york)의 관찰 자료다. 사진은 외관 참고용이며 기술 사양 근거로 사용하지 않았다. 첫 사진의 정확한 기종과 연식은 **확인 필요**.

[Aircraft overhead signs 특허](https://patents.google.com/patent/US20190103043A1/en)는 기존 백열등 표지, LED, 도광판과 층 구조를 설명하는 1차 자료다. 모든 항공기가 그 구조라는 뜻은 아니다. [Astronics의 객실·좌석 시스템 소개](https://www.astronics.com/interior-and-seat-solutions)는 PSU가 별도 객실 시스템 제품군임을 확인하는 보조 자료다.

일반적으로 보이는 회색 하우징을 사진만으로 금속이라고 단정할 수 없다. 수지 종류·도장·렌즈 재질은 **확인 필요**. 선택한 사진은 점등 상태라 소등 시 실제 색과 표면 거칠기도 **확인 필요**. 본 시안의 소등 렌즈는 검은 회색 반무광, 희미하게 남는 회색 그림, 약한 반사로 설계했다. 점등은 호박색이며 빛 번짐은 그림 가장자리 안팎의 좁은 범위에만 준다. 실물의 광학 측정값을 재현한 것은 아니다.

## 선택과 패널로의 번역

어두운 창의 호박색 픽토그램형을 선택했다. 기존 시안의 곡선 두 줄과 커다란 사각형만으로는 벨트를 체결하는 동작이 약했다. 새 그림은 평평한 두 벨트 끝, 속이 빈 버클 몸체, 맞은편 금속 탭, 안쪽 삽입 화살표와 단순화한 손을 구분한다. 복잡한 손가락 묘사는 실제 크기에서 뭉치므로 생략했다. 특정 제조사 그림을 그대로 추적하지 않았다.

실물의 밝은 천장 패널을 그대로 붙이지 않고 얇은 청회색 매립 테두리로 바꿨다. 원본 패널과 같은 우상단·좌하단 모서리 절삭을 사용하고 테두리에는 옅은 시안만 남겼다. 남보라 하우징과 렌즈의 미세한 줄무늬는 HUD 바탕에 이어진다. 호박색은 착용 안내, 시안은 구조, 분홍은 기존 속도계 바늘, 빨강은 레드존으로 역할을 나눈 설계 판단이다. 금연 표시와 작은 영문 문장은 추가하지 않았다. 이 공간에서 벨트 그림의 면적을 확보하기 위해서다.

## 치수와 색

| 항목 | 값 |
|---|---|
| 바깥 하우징 | 64 × 40px, padding 3px, left 0 / top 2px |
| 절삭 | 바깥 6px, 안쪽 5px, 렌즈 3px |
| 그림 | 54 × 28px, viewBox 0 0 54 28 |
| 하우징 | #516070 → #263044 → #141526, 내부 #111023 |
| 렌즈·소등 그림 | #0b0c14 / #677078 |
| 점등 그림 | #ffe4a3 |
| 번짐 | #ffd27a, #ffb84d70; 1px 및 3px drop-shadow |
| 렌즈 테두리 | #4fe3ff30 |
| 표본 바탕 | rgba(10,8,26,.82), 페이지 뒤 #07060f |

최대 72 × 44px 안에 들어간다. 64px는 기존보다 4px 넓으며 원본의 속도계 왼쪽 위 좌표를 유지한다. 그림 안에는 글자가 없다. 페이지 설명 글자는 최소 9px이며 외부 폰트·이미지·이모지·상표는 없다. 머리글과 속도계 일부는 원본 치수·색을 따른 정적 배치 표본이다.

## 동작과 접근성

기본은 소등, `.belt.on`은 점등, `.belt.blink`는 1초 주기의 steps(1,end) opacity 애니메이션이다. 0–0.5초 켜짐, 0.5–1초 꺼짐, 1–1.5초 켜짐, 1.5–1.6초 꺼짐 이후 상태 제어기가 blink를 제거한다. 원본의 0.5초 주기·중간점 전환은 0.25초 간격이므로 수정했다. 애니메이션은 점등층 opacity만 바꾸며 치수·위치는 움직이지 않는다.

동작 줄이기 설정에서는 blink가 계속 점등되고 같은 1.6초 타이머로 꺼진다. 상단 비교 표본은 관찰용 반복, 하단 재생 버튼은 실제 1.6초 종료를 보여준다. role=status와 상태별 한국어 aria-label을 사용하며 두 SVG는 모두 aria-hidden=true다. 깜빡이는 프레임마다 접근성 문구를 바꾸지 않는다. 기존 타이머와 차임 로직은 변경하지 않는다.

## 확인 필요

- 사진 속 첫 PSU의 정확한 기종·연식, 실제 소등 사진, 하우징과 렌즈의 재질 및 광색 수치.
- 항공기별 픽토그램·문장·금연 표시 구성의 시대별 보급 비율. 이 문서는 세 가지 대표 구성을 비교하며 보편적 기종 분류로 주장하지 않는다.
- 실기기 390px 화면에서의 밝기·눈부심과 운영자의 즉시 인지 여부. 브라우저 치수 검증과 별도로 현장 시각 승인이 필요하다.
