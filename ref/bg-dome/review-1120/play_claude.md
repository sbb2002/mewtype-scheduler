# Claude 체험 — UFO 테마 첫 접속부터 끝까지 (feat/bg-dome 5599a2e)

## 방법
- 헤드리스 Chromium(실제 GPU) 390×844 · 터치 에뮬레이션 · 위치 허용(서울). 저장소 빈 상태, `?bgdebug` 만(시선 이동 훅 때문).
- 손길은 전부 실제 터치(CDP): 테마 버튼 길게 누르기 · 레인 튕기기 · 두 손가락 벌리기/오므리기 · 칸 누르기 · 1.3초 길게 누르기 · 스로틀 누르기 · WARP · 목적지 고르기.
- 시선만 자이로 대신 `__bgview`. 대상 위치(`__bgunlock.targets`)는 **보지 않았다** — 화면 왼쪽 아래 맥박 표시기의 색(빨강 = 가까움 … 파랑 = 멂)만 보고 더듬었다(사람이 색 · 박동을 보는 것과 같은 정보).
- 1부(첫 접속 → 별자리 5개 · 별빛 조명)는 한 번에 끝까지. 2부(워프 → 딥필드 5곳 → 달 궤도 → 지구 → 보상)는 1부 끝 상태를 이어받아 새 탭에서(도구 문제로 1부 탭에서 여러 번 끊겨서).
- 기록 `scratchpad/review/play/part1_log.txt` · `play2/log.txt`, 캡처 `play/` · `play2/`.

## 소감
- **좋았던 것**: 맥박 표시기(색 · 박동)가 「뜨겁다/차갑다」 놀이처럼 정확해서 글 안내 없이도 찾는 재미가 있다. LOCKED 순간의 고리 · 불꽃 · 카드 연출은 보상감이 확실하다. 장면은 단계마다 확실히 달라진다 — 분홍 구름 → 은하 → 창조의 기둥 · 게 성운 사진 → 월면 지구돋이. 특히 **달 궤도 지구돋이는 이 이스터에그의 백미**. 자유 항해 칩이 「내가 모은 우주」 목록처럼 보여 수집 완료감이 좋다.
- **지루했던 것**: 워프 한 번 = 패널 열기 → 1초 길게 → 5단 → 13초 경보 대기 → WARP → 도착 → 찾기. 이걸 최소 6번, 운 나쁘면 그 이상(이번 8번 중 2번 헛걸음). 13초 경보가 매번 똑같이 울려 3회째부터는 「또?」가 된다. 중반부 템포가 가장 처진다.
- **헷갈렸던 것**: ① 대상을 잡은 직후(LOCKED) 두 손가락을 벌리면 패널이 아니라 망원 확대가 된다 — 카드에도 「두 손가락으로 벌려도 됩니다(= 확대)」. 같은 손짓이 상황에 따라 「콘솔로 다가가기」와 「확대」 두 뜻이라, 찾은 직후 패널을 열려다 확대만 된다. 시선을 3초 넘게 돌려 잡힘을 풀어야 패널이 열린다. ② 하늘 전환 뒤 패널이 다시 떠서 새 하늘을 가린다(Antigravity 지적 재확인). ③ 처음엔 어디서 튕겨야 하는지 — 카드가 레인을 채우면 빈 곳이 아래쪽 좁은 틈뿐.
- **감동 포인트**: 별자리 다섯을 다 모아 「별빛 조명 열림」이 뜨는 순간, 그리고 월면 위 지구를 잡는 순간. 멤버 탄생 별자리라는 설정이 팬에게 의미가 있다.

## 새로 발견한 것
1. **손을 뗀 클릭이 「되돌리기 판」(#bg-peek-catch)에 떨어져 배경 보기가 닫힘 — 헤드리스에서 반복 재현, 실기기 확인 필요.**
   - 길게 누르기: 도착 직후 첫 길게 누르기 7번 모두 기어 패널이 안 뜨고 `click → #bg-peek-catch` 기록 뒤 예고 화면으로 튕겨 나감(`play2/log.txt` 「원인 기록: ['catch-click', …]」). 따로 떼어 같은 손길을 하면 재현되지 않아 조건(직전 조작 · 타이밍)이 아직 특정되지 않았다.
   - 오므리기(패널 닫기) 뒤에도 같은 현상 1회(`dbg8`).
   - CDP 터치 흉내가 실제 폰과 클릭 생성 규칙이 다를 수 있어 **실기기 확인 필요**. 실제로 일어난다면 「누르기 시작한 곳이 되돌리기 판일 때만 되돌린다」로 막을 수 있다(`bgpeek.js` catcher click).
2. **잡힌 대상이 있을 때 벌리기 = 확대**(위 소감 ①) — 버그라기보다 손짓 뜻 충돌. 운영자 결정 필요.
3. 이미 찾은 대상도 시선을 받아 링이 다시 차오르고 카드가 뜬다 — 다른 대상을 찾는 중에 스치면 잠깐 「잡히는 중」처럼 보여 헷갈릴 수 있다(사소).
4. 지구 이동은 별도 탭에서 정상(위치 확인 → 바깥 보기). 2부 탭에서 한 번 실패한 것은 도구 타이밍 문제로 판단.
