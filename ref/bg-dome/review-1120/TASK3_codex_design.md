## 디자인 과제 (세 모델 검토 · 체험에서 나온 것)
1. **WARP 대기(5단 → 약 13초) 상태 표시** — 경보가 「기어를 내려라」로 오해됨. 「가속 중 → 워프 준비 → 출발 가능」이 보이게. 첫 워프 사진 받는 동안의 준비 표시도.
2. **도착 · 하늘 전환 뒤 조작 패널 자동 재등장** — 새 하늘 감상 · 찾기를 막음(패널이 떠 있으면 바라보기 판정이 꺼짐). 패널 복귀 방식 시안.
3. **대상 잡힌 직후 두 손가락 벌리기 = 망원 확대** — 「콘솔로 다가가기」와 뜻 충돌. 손짓 구분 시안.
4. **첫 방문 안내 겹침 · 발견성** — 안내 4종이 1~6초에 겹침, 튕기기 빈 곳이 좁음, 15초 뒤 안내 영구 소멸, 다시 보는 길 없음, 배경 보기 안에서 하늘 대상을 누르면 닫힘.
5. **지구 진입 위치 권한** — 권한 이유를 미리 · 거절 뒤 다시 시도 · 지구 안내 문구가 이미 레인을 걷은 상황과 안 맞음(bgview.js choose 의 토스트).
6. **해금 · 보상 연출** — 콘솔로 날아간 도형의 착지 반응, 달 궤도 첫 등장 강조(chooserItems 의 signal 미표시), 최종 해금 토스트 2.2초가 짧음, YMMT 첫 1회 보장, 별빛 조명 해금 연출, 자유 항해로 달에 간 뒤 기본 우주 복귀 길.
7. **효과음** — 무음 구간(배경 보기 진입 · 패널 · 하늘 전환 · 도착 · 시선 잡힘 · 기어 변속 · 길게 누르기 충전), 팡파르 · 띵(합성)과 음원 질감 통일, 경보음 피로, 워프 B 소리 시점. → 음원 후보 목록 + 어디에 쓸지.
8. **플레이어 BGM 연동** — 사용자가 누르는 「추천 곡 칩」 방식(듣던 곡은 끊지 않음). 장면별 곡(songs.json 실제 제목만): 초행성X = 超惑星Xへの旅, 오리온 성운 = オリオンをなぞる, 별자리 = ホシアイ, 달 궤도 지구 = 地球最後の告白を, 최종 보상 = Dream Voyage / アイの夢限 등(세 모델 추천 합집합은 scratchpad/review 의 claude.md · codex.md · antigravity.md). 플레이어에 곡 id 재생 함수가 없음 — 필요한 최소 API 도 제안.
