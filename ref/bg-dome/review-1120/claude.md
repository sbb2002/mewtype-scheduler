## UX (시간 순)
1. **진입 장벽이 겹겹**: 테마 버튼 길게 누르기(기본 테마가 기본값) → 레인 빈 곳 길게 누르고 위로 튕기기 → 두 손가락 벌려 콘솔 접근. 세 단계 모두 숨은 제스처라 안내를 한 번 놓치면 이스터에그 전체를 못 만난다(안내는 각각 최초 1회).
2. **딥필드 5곳 탐험이 운에 좌우되는 반복 작업**: 무작위 워프는 이미 탐험한 곳도 균등하게 뽑는다(`bgunlock.randomDest`). 매 워프마다 1→5단 · 좌석벨트 대기가 필요해서, 5곳을 다 채우려면 기대값으로 워프 10회 안팎(쿠폰 수집 문제 — 대략 계산, 실측 아님). 지루함 · 이탈 위험. 아직 안 가 본 곳에 가중치를 주는 게 낫다.
3. **마지막 보상(지구)이 위치 권한 뒤에 있다**: 거절하면 실내로 되돌아가 보상 직후 흐름이 끊긴다(`bgview.choose`).
4. **문서·코드 주석 불일치**: `bgunlock.js` `GUIDE` 주석은 「해금 2초 뒤 자동 이동 + 안내 카드」인데 11-13에 없앴다(`bgdomegl.js:1526` 주석 · SPEC). 이해용 문서 원칙상 병합 전 정리 대상. `?bglive=all` 확인용 파라미터도 SPEC에 「병합 전 정리 대상」으로 적혀 있음.

## 효과 · 연출
- 효과음 성격이 섞여 있다: 경보 · 워프 = 실제 음원, 좌석벨트 「띵」· 해금 팡파르 = 합성 사인파(`bgsound.ding` · `unlock`). 팡파르가 「도 미 솔 도」 단순 아르페지오라 음원 쪽과 질감이 다르다 → 해금도 짧은 음원(반짝임 + 차임)으로 맞추면 통일감.
- **소리 없는 구간**: 배경 보기 진입 · 패널 열림 · 하늘 전환 · 딥필드 도착 · 별자리 발견에는 소리가 없다. 진입(낮은 「웅」 하는 문 열림)과 도착(잔향 있는 짧은 패드)만 넣어도 공간감이 생긴다.
- 효과음은 사용자가 누르기 전엔 못 낸다(브라우저 정책 — `wake()`), 첫 진입 순간 소리는 불가.
