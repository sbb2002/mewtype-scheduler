## 운영자 요청 (2026-11-05, 원문 요약)

> 수평선 아래는 도시나 산, 바다의 모습을 랜덤으로 그려 넣을까 해. UFO 가 상공에 떠 있는 느낌을 주고 현실성을 주기 위함이야.

## 지금 구조 (Claude 가 코드 · 계산으로 확인)

- 눈 = 돔(반지름 1) 수평 중심, 바닥 원판 위 높이 0.24(`EYE0`). 시선은 실내 · 바깥 모두 폰의 실제 방향(AR, 방위 = 진북 기준).
- 하늘은 시선 방향 `d` 로 그린다(`sky(d)` — 사진 하늘 벌 · 해 · 달 · 별). **실제 수평선(d.y = 0)에는 아무 표시가 없고**, 그 아래도 하늘 사진이 이어진다.
- 돔 유리 격자 위도선 18 · 40 · 62°. 18° 선은 눈 높이 때문에 실제 고도 약 4.1° 에 보인다 — 운영자가 「방위 글자 아래 선 = 수평선」으로 오해한 선.
- 바닥 원판(반지름 1, y = 0) 가장자리는 줌 0 에서 실제 고도 약 −13.5° 에 보인다. → **풍경이 보일 띠 = 고도 0° ~ 약 −13.5°**(유리 너머). 줌아웃(`zoomR` 0 ~ 0.6, 뒤로 물러남)하면 앞쪽 띠가 넓어진다. 아래를 내려다보면 바닥이 가린다.
- 바깥 보기는 시각 · 위치별 하늘(낮 · 노을 · 박명 · 밤 이미지 벌 섞기, `uSolar` · `uNight` 등), 실내 보기는 분홍 하늘. 풍경을 두 보기 모두에 넣을지는 아직 미정 — 제안해 달라.
- 한 패스 셰이더, 텍스처는 하늘 · 구름 벌 + 달 사진. 무료 · 빌드 없음 · 외부 라이브러리 금지 · 공식 캐릭터/로고 금지.

## 생각해 볼 것 (Claude 초안 — 검토 · 반박해 달라)

1. **상공 높이 설정과 수평선 강하(dip)**: 높이 h 에서 보이는 수평선은 고도 0° 보다 약 √(2h / R) 라디안 아래(R = 지구 반지름, 굴절 무시 시 h = 1 km → 약 1.0°, 10 km → 약 3.2°). 「상공」 느낌을 주려면 수평선을 0° 보다 살짝 아래에 두는 게 맞는지, 몇 km 로 잡을지.
2. **대기 원근(aerial perspective)**: 멀수록(수평선에 가까울수록) 하늘색으로 바래고 대비가 줄어든다 — 수평선 근처 풍경은 하늘색 안개로 녹아들게. 시각별 하늘색(낮 · 노을 · 밤)과 맞추는 방법.
3. **풍경 종류**: 도시(낮엔 건물 실루엣 · 밤엔 불빛 점), 산(겹겹 능선 · 멀수록 옅게), 바다(수평선 · 해 · 달 반사 띠 — 반사 띠가 해 방향에 맞게). 랜덤 = 방문마다? 하루마다? 위치 기반 고정? 제안해 달라.
4. **구현 방식 후보**: (a) 셰이더 절차적 생성(능선 = 방위각 함수의 노이즈, 도시 = 방위각 구간별 건물 높이 해시, 불빛 = 해시 점), (b) 파노라마 이미지(이미지 생성 · 용량 · 저작권 문제), (c) 둘 섞기. 각자의 장단 · 용량 · 성능.
5. 아래를 크게 내려다볼 때(고도 −30° 이하) 땅이 납작한 평면으로 보여야 하는지, 바닥이 가리니 신경 쓰지 않아도 되는지.
6. 해 · 달 · 별 · 방위 글자 · 렌즈 효과(동시에 상의 중 — `codex_luminary_consult.md`)와 겹칠 때 순서.
