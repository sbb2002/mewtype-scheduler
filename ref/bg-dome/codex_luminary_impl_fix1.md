# 2차 수정: 해 · 달 광원 — Claude 캡처 검토 결과

지금 작업 폴더의 미커밋 수정(네 1차 구현) 위에서 고친다. `bgdomegl.js` · `bgastro.js` 만. git commit 금지. LF.

## 문제 (네 캡처 `_local/luminary-review/` 를 Claude 가 직접 봄)

1. **`sun-20-center.png`**: 8방향 빛줄기는 좋다. 그러나 블룸이 작아져 해가 「작은 별 모양」이다. 운영자 요구는 분명히 **「해는 글로우 효과를 아주 크고 밝게 줘서 크게 보이도록」**이다(3차 작업 `d96f3a0` 의 큰 흰 블룸이 이 요구로 들어간 것). 방법론 표의 σ(0.35 / 1.5 / 6°)는 시작값일 뿐 — 운영자 요구가 우선이다.
2. **`sun-5-center.png`**: 소광으로 해가 주황 점 하나로 거의 사라졌다. 운영자 요구는 뜨고 질 때 **「더 커 보이는 느낌」**이다. 소광은 색을 바꾸되 존재감을 없애면 안 된다.
3. **`moon-5-full.png`**: 고도 5° 보름달이 거의 보이지 않는다(실제 크기 + 소광 + 방위 글자 S 와 겹침). 운영자 요구는 **「수평선 가까이 걸리면 커 보이고 더 노르스름」**이다.
4. 방위 글자(고도 8°)가 낮은 해 · 달과 겹친다.

## 고칠 것

- 해(모든 고도): **원반은 실제 크기 그대로**, 흰빛으로 탄 핵 + **크고 밝은 블룸**(3차 수준 이상 — 폰 세로 화면에서 밝은 덩어리가 화면 폭의 1/4 ~ 1/3) + 지금의 빛줄기 · 베일 · 고스트. 하늘이 전부 하얗게 날아가지 않게만.
- 낮은 해(0 ~ 10°): 소광은 **색**(노랑 → 주황 → 빨강)과 하늘 쪽 따뜻함으로 표현하고, 화면에서의 존재감(블룸 크기 · 밝기)은 높은 해보다 **크게**(약한 미술 보정 — 운영자 확정 사항). 노출을 낮은 해에 맞춰 올리는 「자동 노출」 해석도 가능.
- 낮은 달(0 ~ 15°): 노르스름 → 주황, **눈에 띄는 밝기와 부드러운 따뜻한 광륜**(원반의 몇 배, 은은하게)으로 찾을 수 있게. 원반 크기는 그대로.
- 방위 글자: 해 · 달이 가까우면(화면 거리 기준) 글자를 옅게 — 해는 이미 sunFade 가 있으니 **달도 같은 방식**으로, 두 경우 모두 광원을 가리지 않게 더 확실히.
