`src/frontend/js/bgdomegl.js`만 수정한다(셰이더 + 필요한 uniform 연결). 다른 파일은 건드리지 말 것 — 특히 `bggyro.js` · `bgview.js` · `bgmag.js` · `config.js`(config.js 에는 운영자 시험용 커밋 안 된 수정이 있다. 그대로 둘 것). git commit 금지.

## 운영자 요청 (2026-11-04, 원문)

> 동서남북(NSEW)를 표시해줘. N은 빨간색으로. 이건 마치 격자 위에 HUD 홀로그램 느낌으로 표시해줘.

## 지금 구조 (코드로 확인한 것)

- 바깥 보기(`uOut = 1`)에서 카메라는 실제 방위를 따른다 — `bggyro.gyroAbs()` = 진북 기준 방위(편각 · 보정 포함), `bgdomegl.js` frame() 의 outdoor 분기.
- 돔 유리 격자: `main()` 의 `lat = asin(q.y)`, `lon = atan(q.x, q.z)`. 장면 벡터 = [동, 위, 북] 이라 **lon 0 = 북, +90° = 동, ±180° = 남, −90° = 서**. 경도선 30° 간격이라 네 방위는 모두 경도선 위에 있다. 위도선 18 · 40 · 62°.
- `q` 는 눈 위치 `E` 에서 나간 시선이 돔(단위 구)과 만나는 점이다. 해 · 달 방향(`uSunDir`)은 `d`(시선) 기준이다 — 방위 글자는 **격자(q) 위에** 둔다(「격자 위에」).

## 원하는 모습

- **바깥 보기에서만**. 실내 보기(uOut = 0)는 실제 방위가 아니므로 표시하지 않는다 — **실내 픽셀 차이 0**.
- 네 글자 N · E · S · W 를 해당 경도선 위, 지평선과 첫 위도선(18°) 사이쯤(고도 약 6 ~ 10°, 보기 좋게 정해도 됨)에 놓는다. 글자는 돔 안쪽에서 바르게 읽혀야 한다(거울 글자 금지). 위쪽 = 천정 방향으로 똑바로 선다.
- **HUD 홀로그램 느낌**: 얇은 빛나는 획 + 은은한 번짐(glow), 약간의 투명감. 아주 옅은 주사선 · 미세한 깜빡임은 넣어도 되지만 거슬리면 안 된다(움직임 줄이기 설정은 이미 장면 전체를 멈춘다).
  격자선과 같은 「유리에 비친 표시」 느낌으로 어울리게. 글자 둘레에 작은 HUD 장식(짧은 눈금 · 꺾쇠 등)은 절제해서 넣어도 된다 — 다른 방위 글자(NE 등)나 숫자는 넣지 않는다.
- 색: **N = 빨강**(경고등처럼 또렷하게), E · S · W = 홀로그램 색(시안 · 흰빛 계열 권장, 판단에 맡김).
- **낮(밝은 파란 하늘) · 노을 · 밤 모두에서 읽혀야 한다** — 밝은 하늘에서 시안이 묻히지 않게 대비(어두운 테두리 · 번짐 등)를 챙길 것.
- 크기: 폰 세로 화면(390×760)에서 지평선 근처를 볼 때 글자 높이 대략 화면 높이의 3 ~ 5%. 너무 크면 하늘을 가린다.
- 해 · 달 · 구름보다 앞(유리 표시)이지만 해 원반을 덮지 않도록 해가 가까우면 조금 옅어져도 좋다.

## 제약

- 무료 · 빌드 없음 · 외부 라이브러리 · 웹폰트 · 이미지 파일 추가 금지. 글자는 셰이더 안에서 직접 그린다(선분 · 원호 SDF 등).
- 성능: GPU 비용 지금 + 10% 이내. 반복문은 짧게(글자 4개만 — 지금 보는 방향 근처 글자만 계산하는 식으로 줄여도 됨).
- 선 굵기는 기존 격자처럼 화면 픽셀 기준(`fwidth`)으로 계단 없이.
- 파일을 LF 로 저장할 것(CRLF 금지).

## 확인 (네 쪽 캡처는 `_local/nsew-review/` 에)

서버: `python scripts/serve_local.py 8102` → `http://localhost:8102/src/frontend/?bg=d&bgdebug&bgtime=...`
폰 흉내: 390×760 iframe, `navigator.geolocation` · `permissions.query` 를 덮어써 위치 = 서울(37.57, 126.98), `bgview.js` 의 `setBgView("outdoor")`,
`deviceorientationabsolute` 이벤트로 방향 지정(방위 az 를 보려면 alpha = (360 − az + 편각) — 편각은 `bggyro.declinationDeg()` ≈ −9.03, 즉 alpha ≈ 351 − az; beta = 90 + 올려 보는 각).
오늘(11-04 KST)은 유노 생일이라 원래는 생일 장면이 돔을 멈추는데, 이 작업 폴더의 config.js 에서 꺼 두었다 — 그대로 둘 것.

1. `bgtime=2026-11-04T12:20:00%2B09:00`(남중) — 정남(S) 쪽 수평, 그리고 정북(N) 쪽 수평 캡처.
2. `bgtime=2026-11-04T17:25:00%2B09:00`(해 질 녘, 해 서 ≈ −111°) — 서(W) 쪽, 해와 W 글자가 같이 나오게.
3. `bgtime=2026-11-05T05:30:00%2B09:00`(밤) — 동(E) 쪽.
4. 북동(45°)을 볼 때 N 과 E 가 화면 양쪽에 같이 보이는지.
5. 실내 보기 픽셀 차이 0, GPU 비용 비교.
