## Platform

web

## Users

주 사용자는 일본어 원문을 바로 읽기 어려운 **한국어권 뮤타입 팬**이다. 주로 **폰**으로 들어와 **자신이 보려는 멤버**가 언제 방송하는지, 지금 라이브 중인지 확인하고 그 방송으로 들어간다. 일본어권 팬은 대상으로 두지 않는다.

운영자는 별도 사용자다. 운영 모니터(`monitor.html`)와 관리 페이지(`/admin`)는 운영자용이며 팬 화면의 판단 기준이 아니다.

## Product Purpose

夢限大みゅーたいぷ(무겐다이 뮤타입) 소속 유튜브 방송인 5명의 예약 방송과 라이브 상태를 한곳에 모아 **팬이 원하는 멤버의 라이브 방송에 들어가게 한다**. 멤버 트윗 · 공식 소식 · 게임 행사 · 곡 듣기는 활동을 따라가게 돕지만, 방송 확인을 방해해서는 안 된다.

성공 = 팬이 원하는 멤버의 방송 시각과 상태를 알고 그 방송으로 갈 수 있는 것. 임박했다는 이유로 아무 멤버의 방송으로 안내하는 것은 의도가 아니다(2026-11-02 운영자 확정).

## Positioning

흩어진 멤버 5명의 유튜브 채널 · X 공지를 사람이 일일이 보지 않아도 되도록 한 화면에 묶고, 일본어 글을 한국어로 번역해 보여 주는 한국어권 팬용 예고판이다. 그룹이 직접 운영하는 공식 서비스가 아니라 팬이 만든 비공식 · 비영리 프로젝트다.

## Operating Context

- 데이터는 폰 Automate 알림 중계, YouTube RSS · PubSub · Data API, 멤버 · 공식 X 글에서 온다.
- 화면은 데이터 저장소의 JSON 을 75초마다 다시 읽는다. raw CDN 캐시로 최대 약 5분 늦을 수 있고, 이는 의도된 트레이드오프다.
- 시각은 KST 로 표시한다. 예고보드의 하루는 KST 04:00 ~ 익일 04:00 이며 달력 날짜와 다르다.
- 번역은 Groq LLM 이 만드는 AI 번역이다.

## Capabilities and Constraints

**현재 기능**

- 오늘 예고 · 내일 예고: PC 타임테이블과 카드 보기, 모바일은 멤버별 오늘 카드 + 내일 카드
- 이후 예고, 소식판, 행사 배너, 멤버 트윗 시트(X 공식 카드 + 한국어 번역), 유메미타 플레이어
- 밝게 / 어둡게 전환, 길게 눌러 주소 복사, 생일 스킨(현재 유노), 노노카 지각 이스터에그, 운영 모니터 진입

**제약**

- 서버 상시 가동 없음. 무료 인프라만 사용한다. 유료 서비스는 금액이 작아도 원칙 위반이다.
- 프론트는 Vercel 정적 호스팅, 빌드 없음, ES 모듈. 데이터는 `textContent` / `createElement` 로만 주입한다(`innerHTML` 금지).
- 데이터 스키마 · DOM 구조 · class 이름 · 시간 표기를 바꿀 때는 `docs/SPEC.md` 를 먼저 고친다.
- 용어는 `docs/TERMINOLOGY.md` 를 따르고, 없는 용어는 그 자리에서 뜻을 함께 적는다.
- 대기소 · 프리챗 · 굿즈안내 같은 준영구 프레임이 섞여 들어올 수 있어 날짜의 연도를 생략하지 않는다.
- 번역 면에 원문 사진 · 영상 · 인용을 직접 그릴 때의 조건: X 원문 카드를 함께 제공하고, 작성자 이름 · 핸들 · 작성 시각 · 원본 링크를 두며, 이미지 · 영상 내려받기를 막는다(2026-10-28 운영자 검토).
- 트윗 수명은 X 게시 시각 + 48시간이다.
- 그룹 영상은 근거가 있을 때만 참여 멤버에 올린다. 그룹 채널 프리미어는 방송 카드로 올리지 않는다.

**의도된 결정(2026-11-02 운영자 확인)**

- 예고보드의 하루를 04:00 에 나눈다. 자정을 넘나드는 방송이 많고 04시에는 방송이 없어서다.
- 주소를 감지하지 못한 카드는 채널로 보낸다. 시스템이 영상을 놓친 경우의 편의 장치이며, RSS · PubSub · Automate 가 겹쳐 발생 가능성은 매우 낮다.
- 첫 방문 도움말 화면을 두지 않는다. 지금은 복잡한 기능이 없어 마이크로 인터랙션으로 직접 익히게 한다. 복잡한 기능이 생기면 필요할 때 볼 수 있는 도움말을 준다.
- 눌러 보면 이해되는 아이콘 · 숫자 표시는 허용한다. 익숙한 모바일 동작을 사용자가 이미 안다고 본다.
- 같은 기능을 중복 제공하지 않는다. 트윗 시트는 닫기 단추 없이 끌어 내리기 · 바깥 누르기로 닫는다.

**결정 안 됨**

- 손잡이가 있는 나머지 시트(소식 · 플레이어 · 이후 예고)의 닫기 · 내리기 버튼 제거는 운영자가 검토 중이다.

- 폰 우선은 운영자 판단이다. 실제 방문 기기 비율은 이 문서 작성 때 확인하지 않았다. 기기 환경 판단이 필요한 작업은 Vercel Web Analytics 수치를 먼저 확인한다.

## Brand Commitments

- 표시 이름은 夢限大みゅーたいぷ, 한글 표기는 무겐다이 뮤타입. 플레이어는 「유메미타 플레이어」로 부른다.
- 비공식 팬 메이드 · 비영리 프로젝트임과 관련 권리가 각 권리사에 있음을 하단 디스클레이머로 알린다.
- AI 번역임을 밝히고, 정확한 정보는 공식 채널로 교차검증하도록 권한다.
- Vercel Web Analytics(쿠키 없음)의 익명 수집을 고지한다.
- 삭제 요청이 있으면 예고 없이 서비스가 중단될 수 있음을 알리고, 문의는 GitHub Issues 로 받는다.
- 공식 서비스로 보이게 만들지 않는다.

## Product Principles

1. **원하는 멤버의 방송 확인이 먼저다.** 소식 · 플레이어 · 연출은 그 길을 막지 않는다.
2. **폰에서 먼저 성립해야 한다.** PC 와 요구가 부딪히면 폰에서 방송을 확인하는 경험을 기준으로 정한다.
3. **근거 없이 단정하지 않는다.** 확인되지 않은 참여 · 시각 · 판단은 확정처럼 보여 주지 않는다.
4. **비공식임을 숨기지 않는다.** 공개 글을 정리하되 번역은 AI 결과이고 원문 · 공식 채널이 정본이다.
5. **무료로 오래 돌 수 있어야 한다.** 과금이나 상시 서버가 필요한 기능은 넣지 않는다.

## Accessibility & Inclusion

- 움직임 줄이기(`prefers-reduced-motion`)를 존중한다. 팬 화면과 생일 스킨 코드에 이미 반영돼 있으며 새 움직임도 따른다.
- 키보드 최적화는 현재 목표가 아니다(2026-10-27 운영자 보류 — 아바타 포커스 · 시트 닫은 뒤 포커스 복귀).
- 멤버 · 방송 상태를 색으로 구분하는 표시는 색약을 포함해 색맹이 아닌 사용자 모두가 알아볼 수 있어야 한다. 종료 방송은 흐리게 하되 지나치게 흑백화하지 않는다(2026-11-02 운영자 확정).
- 그 밖의 준수 기준은 정해지지 않았다.
