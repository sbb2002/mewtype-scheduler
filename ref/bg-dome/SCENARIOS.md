# 배경 돔 — 보기별 시나리오 요약 (feat/bg-dome `5be7f04`, 2026-11-05)

운영자 요청(11-05)으로 정리. 수치 · 확률은 `src/frontend/js/bgdomegl.js` · `bgground.js` · `bgterrain.js` 의 현재 코드 기준.
확인용 주소 옵션은 모두 `?bgdebug` 와 함께 쓴다.

## 1. 실내 보기

| 배경 | 확률 | 시작 | 진행 | 비고 |
|---|---|---|---|---|
| **분홍 구름** | 80% | — | 구름 무늬는 방문마다 무작위(같은 구름 사진 두 겹, 하나는 좌우 뒤집어 다른 자리 · 속도), 천천히 흐름 | 산 풍경이면 능선 없이 평평한 지평선(도시 띠는 유지) |
| **우주** | 20% | 반반: 일반 우주 / 성간 이동 | 아래 「항해 시나리오」 | 땅 없음(지평선 아래도 별). 바탕은 아래 셋 중 하나(같은 확률) |

- 뽑기는 방문마다 새로(저장 안 함). 확인: `bgindoor=pink|space`.

### 우주 바탕 (같은 확률, 공통으로 셰이더 별 · 은하 무리 + 웹 딥필드를 얹음)

| 바탕 | 은하수 | 인상 | 확인 |
|---|---|---|---|
| **(가) NASA SVS Deep Star Maps 2020** | 하늘을 크게 아치 모양으로 가로지름, 먼지 틈 · 마젤란 은하 | 실제 하늘처럼 희미한 별이 빽빽 — 오돌토돌한 질감, 중성적 흰빛 + 먼지 갈색 | `bgspace=map` |
| **대안 ESO/S. Brunier 은하수 파노라마** | 지평선을 따라 수평으로 누움(은하 좌표 그대로) | 띠는 밝고 화려(노란 중심 · 분홍 성운), 머리 위는 상대적으로 비고 어두움 | `bgspace=eso` |
| **(나) 그려 만든 우주** | 없음 | 별이 고르게, 보라 · 남색 성운이 옅게 — 가장 몽환적 | `bgspace=shader` |

- 딥필드 = 웹 망원경 SMACS 0723(NASA, ESA, CSA, STScI), 정면 오른쪽 위 약 34° 로 크게(실제 크기 약 0.04° — 연출). `bgdeep=0` 으로 끔.
- 평가용 이미지(별 지도 1.6MB · ESO 2.3MB · 딥필드 0.6MB)는 `assets/bg/eval/`(저장소에 올리지 않음, 폰 확인 사본에만). 병합 전 용량 줄이기 · 출처 정리 필요.

### 항해 시나리오 (상대론적 — 광행차 · 도플러 · 빛 몰림)

| 시작 | 시나리오 | 확률 | 속도 β = v/c | 보이는 모습 | 확인 |
|---|---|---|---|---|---|
| 일반 우주 | 정지 | 80% | 0 | 별 · 은하 · 딥필드 제자리 | `bgvoyage=rest` |
| 일반 우주 | **출발** | 20% | 20초 정지 → 1분 동안 0 → 0.99c → 유지 | 하늘이 앞쪽으로 몰리며(광행차) 앞은 푸르고 밝게, 옆 · 뒤는 붉게 어두워져 사라짐. 가까운 별 궤적이 뒤로 흐름 | `bgvoyage=depart` |
| 성간 이동 | **등속** | 80% | 0.7c 유지 | 앞쪽 푸른 별 무리, 뒤는 거의 깜깜, 궤적이 계속 흐름 | `bgvoyage=cruise` |
| 성간 이동 | **도착** | 20% | 0.99c 20초 → 1분 동안 0 → 정지 | 정면에 몰린 하늘이 원래 자리로 퍼지며 정지 우주로 | `bgvoyage=arrive` |

- 진행 방향 = 돔 정면 지평선. 진행 시점 고정: `bgwarp=<초>`.
- 광행차 `cosθ = (cosθ' + β)/(1 + β cosθ')` — 먼 배경은 앞으로 몰리고(뒤로 흐르지 않음 — 운영자 동의 11-05), 뒤로 흐르는 것은 가까이 지나가는 별(궤적)뿐.
- 도플러 `D = 1/(γ(1 − β cosθ))`: 색 = 흑체 온도 × D(배경 6500K 기준 · 궤적 별마다 5200 ~ 11200K), 밝기 = 배경 D³ · 궤적 D^1.5(각각 상한), 색을 지키는 톤 매핑.
- 궤적 = 유노 생일 장면 UFO 궤적 규칙(밝은 머리 + 9초 선형 감쇠 꼬리 + 넓은 번짐), 약 20줄, 별마다 빠르기 다름.
- 모션 줄이기 설정이면 어느 경우든 정지 우주.
- 시작 상태 비율(반반)은 운영자가 정하지 않아 Claude 가 정함 — 바꿀 수 있음.

## 2. 바깥 보기 (위치 권한 필요 — 테마 버튼 길게 누르기 → 「바깥 보기」)

| 항목 | 정하는 방식 | 내용 | 확인 |
|---|---|---|---|
| **풍경** | 첫 방문 시드로 1/3씩, 기기에 저장 | 도시(USDA NAIP Denver 사진 · 사진에서 뽑은 밤 불빛 점) / 산(USGS 3DEP 실제 Front Range 지형 · Landsat 사진) / 바다(달 · 해 반사 기둥 + 물결 일렁임) | `bgground=city|mountain|sea` · `bgseed=<정수>` |
| **눈 고도** | 첫 방문 시드로 1 · 2 · 3km, 기기에 저장(종류와 따로) | 고도마다 지평선 높이 · 산이 보이는 정도가 다름 | `bgalt=1|2|3` |
| **하늘** | 실제 시각 · 위치 | 낮 → 노을 → 박명 → 밤 이미지 전환. 밤은 어두운 남색 + 지평선 옅은 번짐 — 삭(그믐)일 때의 기준 | `bgtime=<ISO>` · `bgspeed=0|배속` |
| **구름** | 방문마다 무작위 | 두 겹 무작위 배치로 흐름 · 해 · 달을 가림. 실제 날씨 반영은 보류(Open-Meteo — 사용 경험 확인 뒤 결정) | `bgcloudseed=0|<정수>` · `bgcloud=0~1` |
| **해 · 달** | 실제 천문 계산 | 실제 위치 · 위상. 달 = 눈 시야각 크기(CSS 기준 픽셀 0.0213° → 1배 지름 약 25px), 확대하면 배율만큼 | `bgsunalt/az` · `bgmoon` · `bgmoonalt/az` |
| **산 조명** | 해 고도 · 방향 | 사진의 촬영 음영을 지운 뒤 다시 칠함 — 볕 드는 경사가 밝아짐, 낮은 해일수록 긴 그림자 · 해 쪽 공기 빛, 숲 녹색 | |
| **확대** | 배경 보기에서 두 손가락 | 최대 ×30. 확대하면 노출이 광원에 맞춰지고(달 크레이터), 산은 보이는 영역만 정밀하게 다시 굽기 | |
| **방위** | 나침반 + 진북 편각(WMM2025) 자동 보정 | N(빨강) · E · S · W 표시. 운영자 실측: 카카오맵과 대조해 진북 맞음(장시간 이동 누적 오차는 미확인) | |
