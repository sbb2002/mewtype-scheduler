## 배경

팬 사이트 배경이 「UFO 바닥에서 투명한 반구 돔 너머 하늘을 보는 시점」이다. 지금은 낮의 분홍 하늘 한 벌만 있다.
첨부 1 · 2 = 지금 쓰는 낮 이미지(같은 시리즈로 이어지게 할 기준):
- `dome-sky.webp` — 1280×800, 불투명, 먼 분홍 하늘 + 옅은 권운. **좌우 끝이 이어져 가로로 반복**된다.
- `dome-clouds.webp` — 1280×800, **투명 배경**, 아주 성긴 분홍 안개 구름 조각(가까운 층). 역시 가로 반복.

셰이더가 두 장을 한 바퀴(360°)에 3번 감고, 위쪽 끝(약 고도 70°) 위는 하늘 평균색으로 녹인다. 이미지 아래 끝 ≈ 지평선 근처(고도 약 -12°).
태양 · 달 · 별은 **셰이더가 실제 천문 위치로 따로 그린다** → 이미지에는 절대 넣지 않는다.

## 만들 것 — 같은 규격(1280×800 WebP, 하늘 = 불투명 · 구름 = 투명)으로 시간대 3벌

1. **노을/여명(twilight)** — 지평선 쪽 따뜻한 산호 · 금빛, 위로 갈수록 장밋빛 → 보랏빛. 구름 가장자리가 금분홍으로 빛남. 분홍 정체성 유지.
2. **박명 직후(blue hour)** — 보라 · 남보라 하늘, 지평선에 남은 옅은 분홍 띠. 구름은 어두운 보랏빛 실루엣에 가깝게.
3. **밤(night)** — 짙은 남색~자정 보라, 너무 새까맣지 않게(위에 셰이더가 별을 얹는다). 구름은 달빛을 받은 듯 은은한 은회색 · 연보라 가장자리, 아주 성기게.

각 벌 = `sky-<이름>.webp`(불투명) + `clouds-<이름>.webp`(투명) 두 장. 이름 = `twilight`, `bluehour`, `night`.

## 지켜야 할 것

- **실사풍**(사진 같은 구름 · 대기), 그림체 · 일러스트 금지. 지금 낮 이미지와 같은 시리즈로 보이게(구름 양 · 결 · 고도 비슷하게).
- **좌우 이음매 없이 가로 반복**되게 — 생성 후 좌우 끝을 직접 확인 · 보정해 줘.
- 구름 이미지는 진짜 투명(알파). 체커보드 무늬 · 배경색 금지. 85% 이상 빈 공간.
- 이미지 안에 해 · 달 · 별 · 지평선 풍경 · 돔 · 격자 · 유리 · 반사 · 글자 · 사람 · 캐릭터 · 로고 금지. 공식 이미지 참고 금지(첨부한 것은 우리가 직접 만든 낮 이미지뿐).
- 파일 크기: 하늘 한 장 ≤ 120KB, 구름 한 장 ≤ 450KB 를 목표로 WebP 품질 조절.
- 각 이미지의 생성 프롬프트 원문을 `out/prompts.md` 에 적어 줘.

## 2차 의뢰 이유 — 꼭 읽을 것

1차 결과(첨부 3 = `first-try-sheet.png`, 위에서부터 낮(기준) · 노을 · 박명 · 밤, 왼쪽 = 하늘만 · 오른쪽 = 구름 합성)는 다음 문제가 있었다.
1차 때는 첨부 경로 오류로 **낮 기준 이미지를 받지 못했다** — 이번엔 첨부 1 · 2 가 실제 낮 이미지다(`ref-day-sky.png` · `ref-day-clouds.png`).
- **낮 이미지와 같은 시리즈로 보이지 않는다.** 낮은 화면 가득 섬세한 권운 · 층운 결이 깔려 있는데, 1차 세 벌은 거의 빈 하늘이다. 구름 양 · 결 · 분포를 낮과 비슷하게(하늘 이미지 안에 권운 결이 넓게) 맞출 것.
- **박명 구름이 검은 덩어리라 새 떼 · 박쥐처럼 보인다.** 실루엣 덩어리 금지 — 옅은 안개 결로.
- 노을은 지평선(이미지 아래쪽)이 가장 밝고 따뜻하게, 위로 갈수록 장밋빛 → 보랏빛. 셰이더가 실제 해 방위 쪽에 따뜻한 빛을 따로 더하므로 이미지 자체는 좌우가 고르게(한쪽에 해가 있는 듯한 쏠림 금지). 이 노을 한 벌을 해 뜰 때(여명)에도 같이 쓴다.
- 밤은 너무 비어 보이지 않게 아주 옅은 달빛 구름 결을 넓게. 별 · 달은 넣지 않는다.
- 결과는 `out2` 폴더. 1차 `out` 폴더는 건드리지 말 것.
