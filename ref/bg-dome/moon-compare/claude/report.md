# Claude 안 — 달 궤도
- 달을 구(관측자 높이 0.03R)로: 가장자리는 구 실루엣이라 곡면, 사진 수평선 점 H0 을 지나게 맞춤(bghudlogic.moonSphere). 사진 속 월면은 평면 마스크로 지우고 구가 덮음.
- 지표 높이 = 3층 분석적 크레이터(셀 해시, 그릇 + 테두리, 해석적 기울기) + 중간 울퉁불퉁 + 입자. 픽셀 footprint 로 층 진폭 LOD.
- 조명 = 낮은 태양각 + Lommel–Seeliger, 알베도 얼룩, 그림자 쪽 지구빛(푸른 약한 반사).
- 한계: 긴 투영 그림자(지형 그림자) 없음, 지구는 사진 그대로(밝기/위상은 월면 태양과 연동 안 됨), 크레이터 분포가 균일 해시, 폰 실측 없음.
- 성능 우려: 월면 픽셀당 크레이터 3층 × 9셀 + vnoise 다수 — S23 실측 필요.
