# 달 궤도 「지구돋이」 연출 및 셰이더 설계 자문

## 1. 자연스러운 「달에서 본 지구돋이」 연출 방안

현재 구현(`spaceBase` 414~447줄)이 어색한 핵심 원인은 **① 사진 하단 8%(`v ∈ [0.915, 0.985]`)의 좁은 2D 띠를 평면(`d / dn`)에 투영해 거울 반복(`abs(mod(gq, 2.0) - 1.0)`)하면서 원근 줄무늬와 칼레이도스코프 대칭 아티팩트가 발생한 점**, **② 평면 교차(`dot(d, uMoonN) = 0`)로 지평선이 360° 직선 대원(great circle)이 된 점**, **③ 법선·조명 없이 밝기만 복제해 크레이터 입체감과 낮은 태양각 그림자가 전무한 점**입니다.

### A. 사진 패치와 잇는 방법: 「사진 속 지구만 분리 유지 + 사진 월면 폐기 + 절차적 구면 월면」 (하이브리드)
- **비교 검토**:
  1. *사진(지구+전경 월면)을 그대로 두고 아래만 잇기*: 사진 하단 월면과 절차적 월면의 경계(투영 왜곡·해상도·조명 차이)를 ×30 줌에서 숨기는 것이 사실상 불가능합니다.
  2. *지구도 별도 3D 구로 그리기*: 구름 소용돌이·대륙·대기 산란 텍스처가 추가로 필요해 표본기(16개 한도)와 에셋 제약을 넘습니다.
  3. **추천(사진 지구 크로마/위치 마스킹 + 전방위 절차적 달 구체)**: `space-earthrise.webp`(아폴로 8호 AS08-14-2383)는 하늘이 순검정이고 지구가 상단(`uv.y` 상부, `feat` 위치 부근)에 떠 있으며 하단 25%가 월면입니다. 사진 패치 샘플링 시 **지구가 있는 영역(중심 반경 마스크 + 청백색 채도/밝기 가중치)만 남기고 사진 속 월면과 검은 여백은 완전히 마스킹**해 버립니다. 그 아래는 지평선부터 발밑까지 **단일 절차적 달 구체(Sphere)** 로 통일하면 이음매가 원천 제거되고 HUD 표식(`photoDir(PHOTO_C, ft.u, ft.v)`)과 100% 일치합니다.

### B. 지표면·지평선·하늘 연출 요소
1. **곡면 지평선과 먼 능선(Silhouette Ridge)**: 평면 대신 **달 구체 교차(Ray-Sphere Intersection)** 를 사용합니다. 궤도 고도 $h$에 의해 지평선이 자연스러운 원호(dip angle)를 그리며 내려앉고, 지평선 접선 부근에서 레이의 최근접 거리를 이용해 1D 조화함수 능선(실루엣 굴곡 $\pm 0.25^\circ$)을 넣으면 아폴로 사진 특유의 울퉁불퉁한 지평선이 완성됩니다.
2. **절차적 멀티스케일 크레이터와 지형**: 큰 대접형 크레이터(고원 바다/산지 기복) + 중간 크레이터(림 융기·오목 바닥) + 미세 곰보(줌인 시 나타나는 작은 구덩이) 3계층에 FBM 능선을 얹습니다.
3. **낮은 태양각(Grazing Sun)과 긴 그림자**: 아폴로 8호 지구돋이 사진 속 지구의 위상(위쪽이 밝고 아래쪽이 어두운 반달~기울어진 상현)에 맞춰 **태양 방향 `L_sun`을 사진 기준 위쪽·약간 뒤편(지평선 고도 $8^\circ \sim 14^\circ$)** 으로 일치시킵니다. 크레이터 동쪽 벽은 눈부시게 빛나고 바닥과 서쪽 사면은 칠흑 같은 긴 그림자가 지도록 해석적 크레이터 차폐(Analytical Crater Self-Shadowing)를 적용합니다.
4. **지구빛(Earthshine)과 레골리스 입자감(Opposition Surge)**: 달에는 대기가 없어 그림자 속이 순검정에 가깝지만, 떠 있는 지구가 비추는 **은은한 청회색 지구빛(`vec3(0.015, 0.022, 0.032)`)** 이 암부를 살짝 채웁니다. 또한 달 먼지(레골리스)는 람베르트보다 가장자리가 밝게 유지되는 **Lommel-Seeliger + Hapke 후방산란** 특성을 띠며, 미세 결정 반짝임(micro-glint)이 더해진 따뜻한 무채색(`vec3(0.76, 0.74, 0.70)`)이어야 자연스럽습니다.
5. **하늘 처리**: 달 지평선 바로 위(`0° ~ 6°`)는 태양광에 노출된 밝은 월면 때문에 눈/카메라 노출이 줄어드는 효과(Contrast Adaptation)를 주어 지평선 근처의 희미한 별과 성운을 살짝 눌러 주면 아폴로 사진의 강렬한 대비가 살아납니다.

## 2. 셰이더 구현 수준 설계 및 비용 추정

추가 텍스처 표본기 **0개**로 `spaceBase` 내부에서 완결되는 구조입니다.

### A. 구면 지평선 및 레이-구체 교차 수식
달 반지름을 $R = 1.0$, 관측자(궤도선) 위치를 달 중심에서 `uMoonN` 방향으로 $r_c = 1 + h$ (예: $h = 0.038 \implies$ 지평선 복각 $\theta_{\text{dip}} = -\arccos(1/r_c) \approx -15.3^\circ$)로 둡니다. `placePhoto`에서 `MOON_RISE`(예: $26^\circ \sim 38^\circ$)로 `uMoonN`을 기울이면 창문 하단 $12^\circ \sim 40^\circ$ 영역에 곡면 달 표면이 꽉 차게 들어옵니다.

```glsl
// 카메라 위치 C_m = uMoonN * rc (rc = 1.038), 시선 d (단위벡터)
float rc = 1.038;
float b = rc * dot(d, uMoonN);          // dot(C_m, d)
float c0 = rc * rc - 1.0;               // |C_m|^2 - R^2
float disc = b * b - c0;                // 판별식 > 0 이면 달 구체와 교차
```
- **먼 능선(Horizon Rim Displacement)**: `disc`가 0 근처일 때 시선의 방위각 $\phi = \text{atan}(d_T, d_B)$에 대해 4항 사인 급수 $\delta R(\phi) = \sum_{k=1}^4 a_k \sin(k\phi + \phi_k)$로 유효 반지름을 변조(`c0_eff = c0 - 2.0 * deltaR`)하면 레이마칭 없이도 지평선이 산맥처럼 굽이칩니다.
- **교차점 구면 좌표**: $t = -b - \sqrt{\max(\text{disc}, 0.0)}$일 때 달 표면 단위법선(구면 좌표)은 `vec3 P = (rc * uMoonN + t * d); P = normalize(P);`가 됩니다. 평면 투영(`d / dn`)과 달리 **3D 단위 구면 좌표 `P`** 위에서 노이즈를 평가하므로 지평선 근처에서 무한히 늘어나는 줄무늬가 사라집니다.

### B. 절차적 크레이터 + FBM 지형 및 LOD/안티에일리어싱
`P` 위에서 3D 셀룰러(Voronoi 격자 jitter) 크레이터 함수 1개를 3개 옥타브로 호출합니다.
- **크레이터 프로파일 함수 `craterLayer(vec3 p, float scale, float pxFootprint)`**:
  - `vec3 q = p * scale; vec3 i = floor(q), f = fract(q);`
  - 인접 $2\times2\times2$ (또는 최근접 1~2셀)의 해시 중심점 `c = i + 0.5 + 0.38 * hash3(i)`까지의 거리 $r = |q - c| / R_{\text{cell}}$ 계산.
  - **그릇 + 림(Rim) 높이 수식**:
    $$h_c(r) = \begin{cases} r^2 - 1 & (r < 1, \text{오목한 바닥}) \\ \exp(-4.5(r - 1)) \cdot (1 - 2(r-1)) & (1 \le r < 2, \text{융기된 테두리와 이젝타}) \end{cases}$$
  - **해석적 기울기(Gradient)**: 수치 미분(노이즈 추가 호출) 대신 $\frac{dh_c}{dr} \frac{\mathbf{q}-\mathbf{c}}{r}$ 벡터를 직접 더해 표면 법선 변위 $\nabla h$를 한 번에 얻습니다.
- **×30 줌 대응 LOD & 안티에일리어싱**:
  - 픽셀당 달 표면 발자국 크기 `float fw = pxAng * t / max(dot(-d, P), 0.06);` (grazing 각도 보정 포함).
  - 각 옥타브 주파수 $f_k$에 대해 나이퀴스트 감쇠 가중치 `float w = smoothstep(0.45, 0.12, fw * f_k);`를 곱합니다.
  - 기본 배율($\times 1$)에서는 큰 바다/산지(`scale = 6, 18, 55`)가 보이고, 두 손가락으로 $\times 30$ 망원 줌을 당기면 `fw`가 작아지면서 고주파 크레이터(`scale = 180, 600`)와 미세 레골리스 그레인(`scale = 2500`)이 모아레(시머링) 없이 순차적으로 나타납니다.

### C. 조명 모델 (Lommel-Seeliger + 크레이터 그림자)
- **Lommel-Seeliger 월면 반사**: 일반 람베르트(`max(dot(N, L), 0.0)`)는 달처럼 보이지 않고 플라스틱 구처럼 보입니다. 달의 다공성 토양 반사식:
  $$I_{\text{LS}} = \frac{\mu_0}{\mu_0 + \mu + 0.08}, \quad \mu_0 = \max(\mathbf{N}\cdot\mathbf{L}_{\text{sun}}, 0), \; \mu = \max(-\mathbf{N}\cdot\mathbf{d}, 0)$$
  여기에 위상각 후방산란 $B(\alpha) = 1.0 + 0.35 \cdot \text{smoothstep}(0.7, 1.0, -\mathbf{d}\cdot\mathbf{L}_{\text{sun}})$을 곱합니다.
- **크레이터 내부 긴 그림자**: 레이마칭 없이 각 크레이터 셀 내부에서 태양 방향 투영 거리 $s = (\mathbf{q}-\mathbf{c})\cdot \mathbf{L}_{\text{tangent}}$와 태양 고도 $\tan\theta_{\text{sun}}$를 비교해, 반대편 림 높이가 광선을 가리면 `smoothstep`으로 그림자 마스크(`shadow`)를 씌웁니다.

### D. 지구 패치 분리 마스킹
`spaceBase`의 `uSpaceTex.y > 0.5` 블록에서 `uMoonOn > 0.5`일 때:
- 지구 중심 UV(`vec2(0.51, 0.37)`) 기준 반경과 이미지의 청백색 밝기(`max(g.b, g.g) > 0.04 && uv.y < 0.65`)로 지구 원반만 부드럽게 추출해 하늘에 합성하고, 사진 하단의 평면 월면 샘플링 코드는 전부 제거합니다.

### E. GPU 비용 추정 (S23 · 삼성 인터넷 기준)
- **텍스처 샘플**: **0회 추가** (기존 사진 월면 `textureLod` 2회 제거 → 오히려 텍스처 대역폭 절감).
- **ALU 연산**: 화면 하단 달 지표면 픽셀(전체의 약 30~40%)에서만 실행되며, LOD 게이팅으로 멀리 있는 지평선이나 $\times 1$ 배율에서는 고주파 옥타브가 `if (w > 0.001)`로 스킵됩니다. 픽셀당 약 60~95 FMA 수준으로 S23 Adreno 740에서 **0.3ms 미만(60fps 여유 유지)** 입니다.

## 3. 함정과 우선순위 (1차 → 2차 다듬기)

### 주요 함정 (Pitfalls)
1. **지평선 스침각(Grazing Angle) 모아레**: 지평선 바로 아래는 `dot(-d, P)`가 0에 수렴해 접선 방향 발자국이 급격히 커집니다. LOD 계산 시 반드시 `fw`에 `1.0 / max(dot(-d, P), 0.05)`를 반영해 지평선 부근 고주파 크레이터 법선을 평탄화해야 자글거림이 없습니다.
2. **태양 방향 불일치**: 아폴로 8호 사진 속 지구는 위쪽(달 지평선 반대쪽 하늘 방향)에서 빛을 받고 있습니다. 달 지표면의 태양광 벡터 `L_sun`도 반드시 같은 방향(지평선 위 약 $10^\circ$, 지구 쪽 방위)으로 고정해야 지구와 달의 명암이 하나로 묶입니다.
3. **HUD 표식(`earthT`) 정합성**: `bghudlogic.js`의 `hudTargets("moon")`는 `photoDir(PHOTO_C, ft.u, ft.v)`를 가리킵니다. 사진 패치의 중심 `C`와 크기를 건드리지 않고 사진 속 월면만 마스킹해야 기존 해금 판정이 깨지지 않습니다.

### 단계별 우선순위
- **1차 (핵심 구조 전환 — 어색함 즉시 해소)**:
  1. 평면 교차(`d / dn`) 및 사진 하단 띠 거울 반복(`gm, gm2`) 완전 제거.
  2. 구체 교차(`disc = b*b - c0`) + 방위각 사인 급수 지평선 능선 도입.
  3. 3D 구면 좌표 기반 2~3옥타브 해석적 크레이터(높이+기울기) + Lommel-Seeliger 조명 + 사진 패치에서 지구만 마스킹.
- **2차 (디테일 & 망원 완성도 다듬기)**:
  1. $\times 30$ 망원 줌 전용 고주파 마이크로 크레이터 및 레골리스 반짝임(glint) 옥타브 추가.
  2. 크레이터 림 자체 그림자(Analytical Rim Shadow) 및 암부 청회색 지구빛(Earthshine) 보정.
  3. 크레이터 주변 방사형 밝은 퇴적물(Ejecta Rays) 알베도 변조 및 지평선 위 1px 서브픽셀 안티에일리어싱.

## 4. 최종 추천안 (단일 확정안)

**「사진 속 지구만 마스킹해 유지하고, 달 지표면은 추가 텍스처 없이 Ray-Sphere 구체 교차 + 3계층 해석적 3D 크레이터(법선·자체 그림자 포함) + Lommel-Seeliger 조명으로 `spaceBase` 안에서 직접 그리는 하이브리드 구면 월면 안」** 을 최종 추천합니다.

- **이유**:
  1. 새 텍스처나 외부 에셋(출처 표기·다운로드 용량·16개 표본기 한도 문제)이 **전혀 필요 없습니다**.
  2. 구면 기하 위에서 3D 좌표로 크레이터를 생성하므로 원근 줄무늬와 거울 반복 패턴이 **근본적으로 사라지고**, 곡면 지평선과 능선이 실제 달 궤도 사진처럼 휘어집니다.
  3. 픽셀 발자국(`pxAng`) 기반 연속 LOD를 통해 $\times 1$ 광각부터 $\times 30$ 망원 줌까지 질감이 깨지지 않으며, 기존 HUD 지구 해금 좌표와도 완벽히 호환됩니다.
