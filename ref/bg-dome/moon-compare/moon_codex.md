# 달 궤도 지구돋이 연출 제안

## 추천 결론

**기존 사진의 지구를 유지하고, 사진 속 월면은 제거한 뒤 절차적 월면 구면으로 교체하는 안을 추천한다.** 지구는 기존 `uSpaceDeep`에서 읽되 원반 마스크로 합성하고, 월면은 광선–구 교차와 제한된 다중 스케일 크레이터로 만든다. 새 표본기는 필요 없다. 구면의 자세·높이·지구 방향을 하나의 장면 좌표계로 관리하면 폰을 돌려도 지구와 지평선이 붙어 보인다.

이 장면은 달 표면에 서 있는 관찰자보다 **달 저궤도 UFO에서 보는 지구돋이**로 해석해야 자연스럽다. NASA도 아폴로 8호 지구돋이를 우주선의 궤도 운동으로 설명한다. 따라서 가까운 돌을 크게 세우는 것보다, 크레이터 분지·긴 그림자·먼 능선이 보이는 넓은 월면을 우선한다. [NASA의 아폴로 8호 설명](https://www.nasa.gov/image-article/forty-fifth-anniversary-of-earthrise-image/)

## 1. 구도와 사진 연결

현재 `spaceBase`는 `d / max(-moonHn, 0.0006)`로 평면을 만난 뒤 사진 하단 7%가량을 두 번 거울 반복한다. 이는 원경으로 갈수록 무늬를 압축하고, 서로 다른 지형의 조명까지 섞는다. `moonHn = dot(d,uMoonN)`도 대원을 경계로 삼으므로 물리적 월면 가장자리와 다르다. 반복을 더 무작위화하기보다 이 경로를 교체해야 한다.

첫 화면에서는 지구 쪽 월면 가장자리를 돔 고도 약 26~30°에 두고, 12° 부근부터 가장자리까지 월면이 넓게 차도록 조정한다. 지구 중심과 월면 가장자리의 간격은 원본 사진에서 측정한다. 이 고도는 화면 구도 목표이며 실제 궤도 고도와 구별한다. 현재 `MOON_RISE = 26`은 평면을 기울이는 값이므로 새 구면에서도 같은 수치를 그대로 적용하면 맞지 않는다.

사진 좌표에서 지구 중심·반지름, 월면 경계의 여러 점을 측정하고 기존 투영식의 역변환으로 방향 벡터를 얻는다. 구면 중심 방향과 각반지름을 경계 표본에 맞춘다. 사진의 좁은 범위에서 곡률 추정이 불안정하면 가상 궤도 높이를 먼저 정하고, 중앙 접선과 지구 간격만 맞춘다. 임의의 굵은 원호를 추가하면 넓은 화면에서 월면이 작은 공처럼 보일 수 있다.

사진 지구는 검은 배경 전체를 더하지 말고 원반을 덮어쓰는 방식으로 합성한다. 현재 `c += g`는 지구 내부에도 기존 별을 남길 수 있다. 원반 내부는 원본의 밤 부분까지 포함해 불투명하게 가리고, 외곽만 픽셀 크기에 맞춰 부드럽게 처리한다. 사진의 검은 사각 영역과 기존 월면은 사용하지 않는다. 지구 외곽의 얇은 푸른 띠는 사진에 있는 만큼 유지한다.

월면과 지구 모두 같은 `uSpaceRot` 좌표로 계산한다. 광선에 월면 교차가 있으면 지구·별보다 앞에서 가린다. 장면을 들어 올릴 때도 구면, 지구, 태양 방향을 함께 회전한다. 폰의 자세나 줌에 따라 지형 seed를 바꾸지 않는다.

지구를 별도 3D 구로 만드는 대안은 자유로운 위상과 회전에 유리하지만, 현재 사진을 구 표면에 붙이면 대륙이 늘어나며 원래 조명도 중복된다. 구면 지구에는 적합한 전구 지도가 필요하다. 현재 목표에서는 원본 지구의 인지성과 분위기를 보존하는 편이 낫다.

## 2. 구면과 지표 셰이더

카메라를 원점, 단위 시선 방향을 `d`, 월면 중심을 `C`, 반지름을 `R`로 둔다. 다음 식으로 가장 가까운 양의 교차를 구한다.

```glsl
float b = dot(d, C);
float q = dot(C, C) - R * R;
float delta = b * b - q;
// delta < 0이면 하늘. delta >= 0이고 b > 0인 외부 관찰자:
float t = q / (b + sqrt(max(delta, 0.0)));
vec3 P = t * d;
vec3 N = normalize(P - C);
```

이는 가까운 근 `b-sqrt(delta)`의 상쇄를 줄인 형태다. 장면 단위를 `R=1`로 정규화하고 fragment 계산에 `highp`를 쓴다. 관찰자는 구 밖이라는 전제를 유지한다. 일반적인 구 교차와 양의 근 선택은 [PBRT의 구 교차 설명](https://www.pbr-book.org/4ed/Shapes/Spheres)을 따른다.

중심까지 거리 `L=length(C)`에서 월면의 각반지름은 `alpha=asin(R/L)`이다. `mu=dot(d,C/L)`에 대해 경계는 `mu=cos(alpha)`. 이 식으로 가장자리 커버리지를 계산하면 지평선 곡률이 시선 변화에 일관되게 반응한다. 월면 전체 구도를 들어 올리는 회전은 이 기하와 별도로 둔다.

표면은 대규모 완만한 분지, 중간 크레이터, 미세 입자의 세 층으로 만든다. 구면 법선 `N`의 고정 좌표를 쓰면 평면 UV의 원근 늘어짐을 피할 수 있다. 다만 구면 전체의 연속성을 위해 3D 좌표 기반 필드나 경계가 연결되는 구면 패치를 사용한다. 단순 경위도 UV noise는 극점과 경도 이음매를 만든다.

크레이터는 2D 셀의 중심을 hash로 이동시키고 주변 3×3 셀을 검사한다. 중심 거리 `r`에 대해 완만한 음의 분지와 좁은 양의 테두리를 조합한다. 예컨대 `-a*(1-smoothstep(0,1,r)) + k*exp(-((r-1)/w)^2)`를 기본으로 하고, 반지름·깊이·테두리 파손 정도를 seed로 바꾼다. 실제 표면 경사는 해석적 미분으로 구해 법선을 교란한다. 밝은 원무늬만 그리는 것으로 끝내지 않는다. 초기에는 서로 다른 크기 두 층이면 충분하다.

큰 형태에는 2~3옥타브 value noise를 낮은 진폭으로 더하고, 미세 입자는 약한 알베도 변화로 제한한다. 현재 `vnoise`는 3D 보간 한 번마다 여덟 격자 hash가 필요하므로 무심코 여러 번 재평가하지 않는다. 높이와 미분을 함께 반환하면 법선용 유한차분 재호출을 줄일 수 있다.

## 3. 빛, 그림자, 하늘

태양 방향은 원본 월면 그림자와 지구의 밝은 쪽을 참고해 하나로 고정한다. 시작 시안은 낮은 태양각으로 잡되, 과장한 사광이 원본과 모순되면 원본 정합을 우선한다. 무광 회색 알베도에 `max(dot(Ndetail,S),0)` 확산광을 적용하고 정반사는 생략한다. 2차에서는 Lommel–Seeliger 항을 약하게 섞어 월면 특유의 밝기 분포를 다듬을 수 있다.

법선 조명만으로는 긴 투영 그림자가 생기지 않는다. 1차에는 크레이터 내부의 태양 반대쪽에 분석적 가림을 넣는다. 이를 정확한 지형 그림자로 설명해서는 안 된다. 2차에는 큰 지형만 태양 방향으로 4~6회 높이 조회해 접촉 그림자와 테두리 그림자를 보강한다. 광선 마칭 전체를 고해상도로 도입하면 비용이 급증한다.

구면 교차 뒤 법선만 바꾸는 방식은 실루엣에 실제 능선이나 크레이터 굴곡을 만들지 못한다. 가장자리에는 별도 저주파 능선 함수를 각도 좌표에 고정해 약하게 추가하거나, 2차에 경계 부근만 제한된 변위 교차를 적용한다. 멀리 있는 능선의 진폭은 작게 하고, 검은 하늘과 맞닿는 윤곽은 선명하게 유지한다.

월면 그림자는 거의 검게 두되 지구 방향의 약한 청회색 반사광으로 형태를 조금 남긴다. 지구빛은 전 화면 파란 ambient가 아니라 지구를 향한 면에 한정한다. 입자는 표면에 고정하며 떠다니는 먼지나 안개로 만들지 않는다. 달 장면에서는 `nebula`와 `galaxies`를 끄고, 노출상 별은 적고 약하게 남기는 쪽이 자연스럽다. 원경을 대기 안개로 흐리게 하지 않는다.

## 4. 확대, 안정성, 비용

30배 줌에서는 단순 noise를 확대하는 대신 픽셀의 월면상 footprint에 따라 작은 크레이터 층을 순차적으로 활성화한다. 지형 위치와 큰 형상은 유지하고 층별 진폭을 부드럽게 전환한다. 픽셀보다 작은 형상은 필터링된 평균으로 수렴시킨다. 미세 noise를 화면 좌표로 추가하면 폰을 움직일 때 지형이 미끄러진다.

footprint는 `pxAng`와 거리·입사각으로 보수적으로 추정하거나, 교차 위치의 미분으로 구한다. 비균일 분기 안의 `dFdx/dFdy/fwidth`는 피하고, 필요한 시선 미분은 분기 전에 계산한다. 지평선 커버리지도 고정 `0.002` 대신 실제 픽셀 각폭에 맞춘다. 현재 `smoothstep(0.002,-0.002,moonHn)`은 경계 순서가 뒤집혀 있으므로 `1.0-smoothstep(-w,w,x)` 형태로 고친다.

사진 지구의 정보량에는 한계가 있다. 960px 사진에서 작은 지구를 잘라 30배 확대해도 실제 구름 디테일은 늘지 않는다. 절차적 질감으로 대륙을 꾸며내지 말고 원본 픽셀을 부드럽게 재구성한다. 지구까지 고해상도 확대가 필수라면 별도의 검증된 고해상도 원본이 후속 조건이다.

대략적인 추가 작업량은 월면 픽셀당 구 교차 1회, 두 크레이터 층에서 최대 18개 후보, 저주파 noise 2~3회다. 지구 픽셀은 기존 사진 표본 1회로 끝낸다. 지형 그림자 6회가 높이 함수 전체를 재평가하면 지형 비용이 여러 배로 늘 수 있다. 월면이 덮는 픽셀에서는 별·은하·사진을 먼저 계산하지 않도록 분기 순서를 바꿔 기존 낭비를 줄인다.

새 표본기 0개가 기본안이다. ALU가 병목이면 작은 선형 데이터 텍스처 한 장에 높이·기울기를 넣는 대안을 비교할 수 있으나, 활성 표본기 예산을 먼저 확인한다. 프레임 예산은 60fps에서 16.7ms, 30fps에서 33.3ms이며 다른 UI 비용도 포함된다. 실제 S23에서 측정하지 않았으므로 특정 fps는 보장할 수 없다. 전체/월면 확대/지평선 확대를 각각 측정하고 지형 경로의 추가 GPU 비용 2~4ms를 초기 목표로 삼는다.

## 5. 실행 우선순위

1. **1차:** 반복 띠 제거, 구 교차와 곡면 경계, 사진 지구 원반 합성, 공통 좌표 정합, 두 크기 크레이터와 단순 조명. 기본 배율과 30배에서 자세를 바꾸며 경계·별 비침·질감 수영을 확인한다.
2. **2차:** 큰 지형의 제한된 그림자, 실루엣 능선, 미세 질감 LOD, 지구빛과 노출 보정. 열이 오른 기기에서도 프레임 시간을 확인한다.
3. **후속:** 실측에서 필요할 때만 텍스처 또는 제한된 변위 교차를 추가한다. 외부 자산을 도입한다면 해당 NASA/LRO 자료의 권리·크레딧을 개별 확인하고 자산 README에 기록한다.

최종 선택은 **사진 지구 + 절차적 구면 월면 + 분석적 크레이터 음영**이다. 첫 완성의 판단 기준은 무늬의 복잡함보다, 돔 아래쪽을 채우는 월면과 그 위 지구가 하나의 장면으로 이어지는지에 둔다.
