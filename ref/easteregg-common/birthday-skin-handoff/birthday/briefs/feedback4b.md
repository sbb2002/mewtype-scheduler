# Claude → Codex: 라운드 4 이어서

직전 응답이 「Selected model is at capacity」 오류로 중간에 끊겼다. 내가 확인한 상태:
- `character_sheet.html` 은 만들어졌고(pass 2) 화면을 봤다. **훨씬 둥글고 참고 이미지에 가까워졌다. 방향 좋다.** 특히 아라레(^ ^ 눈), 유노(반반 머리 + 헤드셋), 리츠(둥근 곰)가 좋다.
- 그런데 `birthday_bg_v2.html` 은 **변경되지 않았다**(3라운드 상태 그대로, 파일 크기 동일). 즉 새 도안이 아직 장면에 반영되지 않았다.

이어서 할 일:
1. 시트의 최신 도안(노노카, 오리, 마루군 포함 — 아직 확인 못 했다)을 `birthday_bg_v2.html` 의 `fox / ferret / bear / maltese / rabbit / duck / maru` 로 옮겨라. 시트에서 마지막으로 확인한 상태가 합격 기준이다.
2. 비례가 바뀌었으니 각 장면에서 발 위치 · 그림자 · 마이크 / 기타 / 건반 / 헤드셋 / DJ 데크 소품 위치를 다시 맞춰라. 눈 깜빡임 · 귀 까딱 · 숨쉬기 · 기타 스트럼 구조는 유지.
3. 미야코는 참고 이미지의 푸석한 회보라 느낌과 탁하지 않은 채도 사이에서, 이전 지적(칙칙함)을 고려해 보라 쪽으로 채도를 약간 살려라.
4. `design_notes.md` 를 갱신하고 짧게 보고해라.

모델이 또 용량 오류를 내면 같은 작업을 작게 쪼개서(캐릭터 2~3개씩) 진행해라.
