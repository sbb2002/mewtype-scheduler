# Claude → Codex: 라운드 3 (운영자 직접 피드백)

운영자가 v2 를 보고 말했다. 원문 요지:
1. 「퀄리티가 오른 건 좋다. 그런데 **이질감**이 든다. **내가 알려준 이미지와 동일하게 그려주길 바랐다.**」
2. 「캐릭터를 그릴 때 **실제 동물처럼 그리기보다 저 캐릭터를 똑같이** 그리면 된다.」
3. 「아라레의 신라면은 **실제 신라면 봉지를 약한 블러 처리**해서 진짜 신라면 봉지 같은 느낌을 줘야 한다.」

## 내 진단 (v2 의 이질감 원인)
v2 캐릭터는 윤기 나는 **3D 풍선 인형** 질감 + 실제 동물에 가까운 비례다. 참고 이미지(`refs3/`)의 캐릭터는 전혀 다르다: **납작한 2D 치비 마스코트**다 — 머리가 몸의 절반 이상인 둥근 실루엣, 짧은 몸통과 뭉툭한 손발, 점 같은 눈(혹은 감은 눈 호선), 분홍 볼 타원, **가는 갈색/진한 색 외곽선**, 단순한 셀 셰이딩(한 겹 그림자), 파스텔 단색 면. LINE 스티커처럼 평면적이다.

## 이번 라운드에서 할 일
`birthday_bg_v2.html` 을 수정하되(백업 `birthday_bg_v2_round2_backup.html` 있음), **캐릭터를 처음부터 다시 그려라.**
- 먼저 `refs3/` 의 5장과 `refs/` 3장을 전부 열어서, 멤버별로 **무엇이 보이는지 직접 관찰해 목록으로 적어라**(귀 모양, 얼굴 비례, 볼터치, 옷, 소품, 색). 추측하지 말고 보이는 것만. 안 보이는 부분은 「불명」이라 적고 가장 단순한 쪽으로 처리.
- 내가 관찰한 것(참고용, 네가 다시 확인해라): 
  - 아라레 = 노란 여우(페넥형). 크고 뾰족한 귀, 볼 털 뭉치, 끝이 크림색인 풍성한 꼬리, 점 코, 마이크를 듦. LINE 스티커의 여우는 검은 재킷 + 흰 셔츠 + 넥타이, 머리에 청록 지그재그 핀.
  - 유노 = 둥글고 통통한 분홍 동물. 머리가 **붉은색/분홍색 두 톤으로 갈림**(머리카락 같은 무늬), 작고 둥근 귀, 헤드셋 마이크, 어두운 점퍼. 루프 GIF 에서는 분홍 몸에 가늘고 긴 꼬리.
  - 리츠 = 연한 하늘색 곰. 둥근 귀, 큰 어두운 눈, 분홍 볼. 스티커에 기타를 든 모습.
  - 미야코 = 보라색 **털이 푸석푸석 흐트러진** 강아지. 키보드(멜로디언형)를 연주.
  - 노노카 = 분홍 토끼. 긴 귀, 기타.
  - 오리와 마루군은 참고 이미지가 없다. 같은 2D 치비 스타일 규칙으로 보라 톤에 어울리게 그려라.
- **스타일 규칙**: 외곽선 있는 2D, 풍선 같은 방사형 그라데이션과 유리 같은 하이라이트 제거. 얼굴 · 귀 · 꼬리 · 팔을 층으로 나눠 움직이는 구조는 유지(눈 깜빡임, 귀 까딱, 숨쉬기 정도의 느린 움직임).
- **배경과의 어울림**: 캐릭터가 2D 라서 배경이 사진처럼 실사면 이질감이 다시 생긴다. 배경도 **애니메이션 배경화(채색된 일러스트풍)** 쪽으로 톤을 맞춰라. 참고 `ref_mv_animal_park.png` 의 밤 공원처럼 하트 · 별 · 나무 실루엣이 있는 동화풍. 다만 v2 에서 좋았던 요소(대기 원근, 부드러운 바닥 그림자, 패럴랙스, 그레인, 환경광이 캐릭터에 살짝 물드는 효과, 유노만의 느린 아웃런)는 **유지**해라. 즉 「2D 캐릭터 + 질감 있는 일러스트 배경」이 목표이고, 3D 인형 느낌만 걷어낸다.

## 아라레의 신라면 (`refs3/ref_shin_ramyun_packet.png`)
- 상품 이름과 모양이 곧 소품이므로 **실제 봉지처럼** 보여야 한다. 이미지의 봉지를 관찰해 SVG 벡터로 충실히 재현해라: 붉은 바탕, 위아래의 톱니 모양 실링, **굵은 붓글씨 검정 「辛」** 과 그 뒤의 금빛 한자 세로줄 무늬, 오른쪽 「라면」 글자, 아래쪽 검정 띠(번개 모양 경계)와 그릇에 담긴 면 이미지, 비닐 특유의 주름과 광택.
- 외부 사진 파일을 넣지 마라(CSP + 복제 금지). **직접 그린 벡터**여야 한다.
- 회사 로고 마크와 작은 글씨는 **선명하게 새기지 마라.** 전체에 **약한 블러**(stdDeviation 0.6~1.0 정도)를 걸어 작은 글씨는 뭉개지고 큰 「辛」과 색 덩어리만 읽히게 해서, 멀리서 보면 진짜 봉지, 가까이서 보면 살짝 초점이 나간 느낌이 되게 한다.
- 날아다니는 연출, 회전, 접촉 그림자는 유지. 봉지 크기를 v2 보다 약간 키워 알아볼 수 있게.

## 유지할 것
탭 UI, 폭죽 · 움직임 멈춤 · 배경 끄기 버튼, 모션 줄이기 · 숨은 탭 정지, 리츠의 고속 궤적(5초대 주기), 각 멤버의 환경 구분(유노만 아웃런), 외부 리소스 없음.
