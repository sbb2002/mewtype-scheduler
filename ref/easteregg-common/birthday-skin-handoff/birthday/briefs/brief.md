# 작업 의뢰 (Claude → Codex)

너는 이 작업의 **디자인 리드**다. 운영자가 「디자인은 Codex가 더 낫다」고 했다. 나(Claude)는 검토와 피드백을 맡는다. 한국어로 답해라.

## 무엇을 만드나
팬 사이트(夢限大みゅーたいぷ, 무겐다이 뮤타입)에서 멤버 생일 당일에 배경을 바꾸는 이스터에그. 이번 단계는 **단일 HTML 파일 시제품**(`birthday_bg_v2.html`, 현재 디렉터리에 저장)이다. 멤버 5명 장면을 탭으로 전환해 본다.
- `birthday_bg_v1.html` = 내가 만든 1차 시제품. `spec.md` = 명세. 둘 다 읽어라.
- `refs/` 이미지 3장 = 공식 MV · LINE 스티커의 「ゆめみた animals」 참고 화면. **캐릭터는 이 이미지의 디자인을 따라 다시 그려라.** (이미지를 직접 열어 봐라.)

## 운영자 피드백 (원문 요지)
1. v1 은 5명 모두 synthwave/outrun 테마였다. **outrun 은 유노만.** 그 이동 속도도 너무 빨랐다 → **훨씬 천천히.** 나머지 4명은 각자 완전히 다른 환경이어야 한다(격자 바닥 재사용 금지).
2. 캐릭터가 5명 모두 의도와 달랐다. 참고 이미지(구글 「yumemita animal」)대로: **리츠 = 파란 곰**, 나머지는 각자 컬러에 해당하는 동물 캐릭터.
3. 전체적으로 **너무 플래시 애니메이션 같다.** 더 고품질이고 **실감나게**.

## 멤버별 요구 (운영자 원문)
- 아라레: 페넥 여우 또는 계란후라이 같이 생긴 캐릭터. 발랄하고 노란 톤의 행복한 분위기. 신라면이 날아다님(상표 · 포장 도안 · 글자 금지 — 붉은 봉지 + 「辛」 한 글자 정도로 일반화).
- 유노: 족제비 캐릭터. synthwave 배경 + DJ 이퀄라이저 애니메이션. 붉은 톤.
- 리츠: 파란 곰. 라멘과 햄버거가 둥실 떠다님. 전체적으로 푸른 톤. 고속으로 궤적을 남기며 날아다니는 무언가.
- 미야코: 신비로운 보라 톤. 오리 캐릭터, 강아지 모양 마루군, 그리고 본인을 뜻하는 보라색 말티즈. (참고 이미지의 보라 강아지가 미야코 쪽 동물이다.)
- 노노카: 분홍 토끼 + 기타. 귀엽고 포근한 분홍빛 배경.

## 품질 기준 (가장 중요)
- 「플래시 애니메이션」 느낌 탈피: 단색 + 굵은 외곽선 금지. 그라데이션 셰이딩, 림 라이트, 부드러운 접촉 그림자, 대기 원근(원경은 흐리고 저대비), 피사계 심도(전경 블러), 필름 그레인 · 비네팅, 빛 번짐(bloom), 재질감(털, 유리, 습기 등)을 써라.
- 입체감: 일관된 수평선 · 소실점 · 광원 방향. 레이어별 깊이 패럴랙스(포인터). 가능하면 CSS/SVG 필터(feGaussianBlur, feTurbulence, feSpecularLighting 등)와 Canvas 를 적극 사용. 단 모바일 성능을 고려해 필터 면적을 제한.
- 움직임은 천천히 · 숨 쉬듯. 번쩍임은 초당 3회 이하. `prefers-reduced-motion` 이면 정지 장면. 「움직임 멈춤」 버튼 유지. 탭이 숨겨지면 정지.
- 캐릭터는 SVG 로 직접 그리되 얼굴 · 귀 · 꼬리 · 악기 등을 층으로 나눠 움직여라(눈 깜빡임, 귀 까딱, 숨쉬기).

## 기술 제약
- 단일 HTML 파일, 외부 이미지 · 외부 스크립트 금지(Google Fonts 만 허용). 이 파일은 CSP 가 걸린 샌드박스(claude.ai 아티팩트)에서 열린다: `fetch` · 외부 이미지 불가, 인라인 JS/CSS · data: URI 가능.
- 참고 이미지를 파일에 포함하거나 복제(트레이싱)하지 마라. **디자인(종 · 색 · 비례 · 소품)을 참고해 직접 새로 그려라.**
- 페이지 UI(멤버 탭, 폭죽 버튼, 움직임 멈춤 버튼, 생일 문구)는 v1 과 같은 기능을 유지하되 더 다듬어도 좋다.
- 다른 파일은 수정하지 마라. `birthday_bg_v2.html` 과 `design_notes.md`(설계 결정과 근거, 한계) 두 파일만 만든다.
