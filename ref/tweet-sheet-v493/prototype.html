트윗 시트 v4.9.3 시제품

구현을 마쳤을 때 예상되는 화면입니다. 미디어 격자는 실제 X 카드 규칙으로 고쳤고, 시트는 「예시 모음」으로 열리며 아래에 두 면을 나란히 놓은 비교가 있습니다. 왼쪽 시트를 그대로 만져 보세요. 멤버 · 글 · 사진은 예시이고, 사진은 그림 대신 색 상자이며, 원문 면의 검은 카드는 진짜 X 카드를 흉내 낸 것입니다. 실제로는 카드 안의 사진을 누르면 X 가 새 창으로 열립니다.

예고판의 멤버 아바타 자리입니다. 누르면 트윗 시트가 열립니다.

해 볼 것

  1. 맨 아래로 열기 — 처음 열면 맨 아래 최신 글입니다. 칩으로 다른 멤버에게 처음 가도 맨 아래입니다. 위로 올려 둔 멤버로 돌아오면 보던 자리입니다. ✕로 닫고 다시 열면 또 맨 아래입니다.
  2. 메신저처럼 — 글 위에 따로 있던 시각 줄을 없앴습니다. 시각은 말풍선 바닥 줄에 한 번만(「21:02」, 올리면 날짜 · 「N분 전」), 날짜가 바뀌는 곳엔 「10월 28일 (화)」 구분선이 들어갑니다. 말풍선 왼쪽 아래 모서리를 좁혀 꼬리처럼 보이게 했습니다.
  3. 겹쳐 밀기 — 글을 옆으로 끌거나(마우스 · 손가락 · 트랙패드 가로), 글을 고르고 ← →, 위 「번역 · 원문」. 두 면 높이가 같아 바꿔도 목록이 움직이지 않습니다.
  4. 번역 면 미디어 — 번역 면이 카드와 같은 뼈대입니다(머리 줄 → 본문 → 사진 · 영상 → 인용 글 → 바닥 줄의 작성 시각). 번역이 원문보다 짧으면 원문 높이만큼 자리를 잡아, 넘겨도 사진 · 인용 · 시각이 같은 자리에 있습니다. 사진은 번역 면에서 그대로 보고, 누를 수 있는 건 영상(▶) 칸뿐입니다. 영상 칸을 누르면 그 글만 원문 카드로 넘어갑니다. 사진을 우클릭해도 저장 메뉴가 나오지 않습니다.
  5. 미디어 여러 개 — 「미디어 여러 개 예시 보기」(또는 칩 「예시 모음」)에 사진만 1~4장 · 사진과 영상 섞음 · 영상만 1~3개 · 인용 글 안 여러 개를 모아 두었습니다. 2칸 = 좌우, 3칸 = 왼쪽 큰 칸 + 오른쪽 위아래, 4칸 = 2×2. 영상 칸에만 ▶가 붙습니다. 사진 칸은 누를 수 없습니다(번역 면에서 보는 것으로 충분). 영상 칸을 누르면 원문 카드로 넘어가고, 카드의 같은 영상 칸 가장자리에 글로우가 한 번 깜박입니다. X 는 글 하나에 최대 4개라 5개 이상은 없습니다.
  6. 맨 아래로 버튼 — 위로 조금 올리면 오른쪽 아래에 ↓ 동그라미가 뜹니다. 그 상태에서 「새 글 도착」을 누르면 숫자가 붙고 흔들립니다. 맨 아래에서 누르면 새 글이 아래에서 떠오릅니다.

시제품과 실제가 다른 곳

  • 영상: 시제품의 카드 ▶는 누르면 「재생 중」을 보여 줍니다. 실제 X 카드는 우리가 재생을 시킬 수 없어 카드 안 ▶를 한 번 더 눌러야 합니다. PC 에서는 그 한 번이 바로 카드에 닿게 덮개를 미리 비켜 둡니다.
  • 위치 맞추기: 번역이 원문보다 길면 그만큼 아래 칸이 내려갑니다(원문 카드는 우리가 줄일 수 없음). 실제 구현에서는 원문 높이를 X 카드 글꼴 치수로 미리 재서 맞추므로 몇 px 차이가 날 수 있습니다.
  • 터치: 실제로는 X 카드 위에서 손가락으로 밀면 카드(iframe)가 가져갑니다. 원문 면에서 번역으로 돌아올 때는 시각 줄이나 점 줄을 밉니다. 시제품은 카드 위에서도 밀립니다.

고친 미디어 격자 — 번역 면과 원문 카드를 나란히

실제 X 카드를 재서 얻은 규칙으로 고친 모습입니다(10-28). 2~4칸은 묶음 전체가 16:9 상자이고, 1칸은 원래 비율이되 세로로 긴 사진은 정사각형으로 잘립니다. 칸 사이 2px, 테두리 1px, 모서리 12px입니다. 인용 글 사진은 인용 상자 아래에 가장자리까지 붙습니다. 왼쪽은 우리가 그리는 번역 면, 오른쪽은 X 카드를 흉내 낸 원문 면입니다. 실제 시트에서는 두 면이 같은 자리에 겹쳐 있습니다. 여기서도 영상 칸을 누르면 오른쪽 카드의 같은 영상 칸에 글로우가 한 번 깜박입니다.
