# 유노 생일 대사 스크립트 (점검용)

코드(`hotfix/yuno-story-arc` 의 `bdaystorylogic.js` · `bdaystory.js`)에서 생성했다. 대사는 곡 안의 시작 시각 기준으로 7~9초 떠 있다(첫 인트로는 약 5~6초). 「/」 는 줄바꿈이다. 문구 안의 시각은 초를 내림해 적었다(3:23.8 → 3:23).

## 먼저 볼 것

- **1곡 3:01 → 3:23 공백이 22.8초다.** 3:12 대사를 삭제한 결과다. 마무리 구간은 음악만 두기로 운영자가 정했다(공백 15초 기준의 예외로 self-check 에 등록).
- **「 // 」** = 좁은 화면에서만 줄을 나누는 자리(3줄까지 허용). 넓은 화면에서는 한 줄로 이어진다.
- **사인이 나오는 동안**에는 다른 대사가 쉬고, 1곡 1:50 · 2곡 2:16 대사만 사인을 피해 낮게 뜬다. 세로 화면은 유노 머리 위, 가로 화면은 유노 왼쪽 하늘.
- **표기:** 「있는거지」 → 「있는 거지」, 「저 녀석들...」 → 「저 녀석들......」 로 띄어쓰기 · 말줄임표만 맞췄다.

## 경우 3. 두 곡을 소리 켜고 들었을 때 — 감사 카드와 그 뒤

조건: 1곡 98% 이상 + 2곡 96% 이상 재생, 소리 켜짐.

| 시각 | 표시 |
|---|---|
| 2곡 3:32 | 감사 카드 |
| 카드 제목 | “......고마워” |
| 카드 본문 | “생일 같은 거 별거 아니라고 생각했는데, / 오늘은 의외로 나쁘지 않았어. / 나중에 YUNO's PARTY Lv.3도 와줘. 기다릴게.” |
| 서명 · 버튼 | — yuno · 「이 순간 간직하기」 |
| 버튼을 누르면 | 카드가 터지고 큰 밤 풍경 시작 |
| 밤 풍경이 끝나면 | 자, 이제 너의 음악을 들려줘. / 너의 턴이야. (1회) |
| 그 뒤 | 곡 대사 없음. 이전/다음 곡 · 폭죽 · UFO · 사인 · 유성우 버튼 열림 |

## 경우 4. 카드 조건을 못 채우고 1곡으로 돌아왔을 때

소리를 끈 구간이 있어 조건이 안 된 경우다. 2곡 끝에서 카드 없이 1곡으로 돌아간다. 피날레는 그 회차에 한 번 나온다.

- 인트로 세 줄(0:00 · 0:07 · 0:12)은 다시 나오지 않는다. 첫 대사는 1곡 0:30 이다(현재 동작과 같음).
- 그 뒤 대사는 경우 1 · 2 와 같은 시각에 나온다.

## 경우 5. 음소거 또는 볼륨 0

| 상황 | 표시 |
|---|---|
| 재생 중 | 곡 대사가 나오지 않는다 |
| 무음이 1분 이어지면 | ......안 듣고 있는 거. / 알고 있거든? (방문당 1회) |
| 소리를 다시 켜면 | 그 시각의 대사부터 다시 나온다 |
| 판정 | 무음 구간은 감상으로 세지 않는다. 곡 끝이 무음이면 그 곡은 완곡이 아니다 |

## 경우 6. 일시정지 · 건너뛰기

해금 전에는 건너뛸 수단이 없다(이전/다음 곡 버튼 · 방향키 · 재생 위치 막대 없음). 일시정지하면 대사도 그 자리에 멈추고, 다시 재생하면 이어진다. 일시정지한 시간은 감상으로도, 감점으로도 세지 않는다.

## 경우 7. 이미 보상을 받은 브라우저로 다시 왔을 때

음악과 장면은 그대로 나오지만 **유노 대사는 인트로 세 줄을 포함해 하나도 나오지 않는다.** 감사 카드도 없고, 피날레는 나온다. 이전/다음 곡 · 효과 버튼은 인트로가 끝나면 열린다.

## 경우 8. 전체 화면이 아닐 때

대사와 카드는 전체 화면에서만 보인다. 일반 화면에서는 음악만 이어진다.
