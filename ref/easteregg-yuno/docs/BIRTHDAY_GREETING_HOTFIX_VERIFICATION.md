# 생일 연출 핫픽스 검증 — v4.11.2 (2026-11-01)

운영자가 핫픽스 등급으로 요청한 인사말·모바일 배치·배경 이벤트·유메미타 음악 우선권 보완이다. 기존 검증 후 병합·배포 승인에 따라 진행한다. 백엔드와 음원 자산은 변경하지 않는다.

## 확인한 동작

- `scripts/verify_birthday_greeting.py`: PC 1440px, 모바일 390/320px에서 두 줄의 시차 등장, 완전 공개, 페이드 중간/끝의 실제 opacity, 모션 줄이기에서 이동/글로우 생략을 확인했다. 공개 4.8초 후 2.8초에 걸쳐 사라진다.
- `scripts/verify_birthday_player_ui.py`: PC 1440×900, 모바일 390×844·360×800·320×740에서 기존 마우스/CDP 터치 이동·호버·재생·키보드·회전·정리 검사 통과. 모바일 제목의 우측 여백 14px, 제목/플레이바 사이 12px 이상, 제목/하단 안내 사이 여백을 확인했다. 제목은 플레이바를 옮겨도 우하단에 남는다.
- `scripts/verify_birthday_sky.py`: 실제 Canvas 픽셀 비교로 작은 별·폭죽·유성 표시를 확인했다. 모션 줄이기에서 별/폭죽 픽셀 차이는 0이다. 모바일 펄스가 이전 상단 클립 위에 그려지는 픽셀을 확인했다(390px 26,727개, 320px 19,044개). UFO 1/2의 실제 drawImage 중심을 71회 샘플링해 모바일 화면 내 체류율 98% 이상을 확인했다. 경로가 무작위이므로 비율은 실행마다 조금씩 다르다.
- 같은 검사에서 유메미타 우선 상태 전달 후 스트리밍/예약 버퍼 BGM 일시정지, 예약 소스 해제, 우선 상태 중 재시작 차단, 대기 중 재생 취소, 자동 재개 없음과 수동 재개를 확인했다. 실제 YouTube 네트워크 재생 대신 공유 우선권 모듈을 사용하며, `player.js`의 실제 PLAYING/BUFFERING/오류 콜백 연결은 코드로 확인했다.
- `bdaystars.selfcheck.mjs`: 무작위 계획 100개에서 고정 연출 제외·여백·5초 이상의 휴지 간격·종류 다양성·같은 방문/시각의 결정적 결과를 확인했다. 인트로, 기존 유성 전체 수명, 드롭, 오로라, UFO/잔상 구간과 겹치지 않는다. 계획의 시드와 위치는 방문/곡마다 달라진다.
- 프론트 self-check 12개 통과. `verify_birthday_performance.py --headed`: NVIDIA RTX 4080 SUPER의 실제 GPU Canvas에서 5개 구간 각각 120회 측정, 최댓값 4.7ms·구간 p95 최댓값 4.4ms. 모바일 실기기 GPU 성능 측정을 대신하지 않는다.
- `scripts/verify_birthday_lifecycle.py`: 자동재생 차단과 탭 시작, 볼륨 복원, 예약 곡 전환 gap 0, 정지 탐색 오차 0, 정리/자정 후 Audio·AudioContext·blob·RAF 0. destroyBirthday 후 생일 소유 리스너 0. 우선권 구독도 직접 해제한다.

화면 캡처와 JSON은 운영자 PC의 `%TEMP%/birthday-greeting-motion`에 저장했다. 실제 삼성 브라우저·iPhone 하드웨어의 터치/음향 확인은 운영자 후속 확인 대상이다. 에뮬레이션을 실기기 검증으로 간주하지 않는다.
