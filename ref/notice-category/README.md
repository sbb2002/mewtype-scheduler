### 4-1. 2차 결과를 합격 기준으로 다시 채점 (3차 정답표 기준, `round2/score_A.md` · `score_B.md`)

A 는 잘못 붙임(FP)이 0 이고 틀림이 전부 **빠뜨림(FN)** — 복수 분류의 두 번째 분류(공연 굿즈의 live, 릴리즈 이벤트의 goods, 공연 생중계의 live)와 외부 커버 MV(#24)를 빠뜨리는 유형. 3차 예시 보강의 표적.

**FP 를 더 무겁게 보는 지표 — F0.5**(운영자 10-23: FP = 틀린 소식을 전함 → 앱 신뢰를 크게 깎음, FN = 맞는 소식을 놓침 → 덜하지만 잦으면 마찬가지).
F-beta 의 beta = 0.5 는 precision 을 recall 의 2배 무게로 본다(`BETA`). 분류별 F1 · F0.5 와, 기준 4분류의 정답 수 가중 평균을 함께 낸다.
B 는 「실효」도 낸다 — `related=false` 로 버린 글은 소식이 안 올라가므로 분류가 하나도 없는 것으로 계산.

| 안 | 가중 precision | 가중 recall | 가중 F1 | **가중 F0.5** | 잘못 붙임(FP) | 소식 자체 누락 |
|---|---|---|---|---|---|---|

## 5. 3차 계획 (10-24 이후 — 운영자 진행 지시 뒤) — 10-23 10:05 실행, 결과 §4-2

   정답표 글을 그대로 예시로 넣으면 점수가 부풀므로 **일반화한 문장**으로 쓴다. 넣은 문구는 이 문서에 덧붙인다.

4. **채택 규칙(10-23 운영자 확정 — 아래 「합격 기준」을 대신함)**: **2차 A 안이 합격선**. 그보다 높은 안이 나오면 그중 가장 높은 안을 채택하고,
   몇 번 시험해도 2차 A 안보다 나은 안이 없으면 **2차 A 안을 채택**한다.
   비교 지표는 기준 4분류의 정답 수 가중 **F0.5**(2차 A = 97.3%, precision 100% · recall 88.9% · FP 0 · FN 5) + **라이브공연 FP 는 1건도 안 됨**(운영자 확정 — 운영자 표현은 「라이브방송」, 라이브공연(`live`)으로 이해함).
